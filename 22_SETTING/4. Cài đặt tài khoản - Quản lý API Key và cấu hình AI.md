## Quản lý API Key

Tab **API Key** hiển thị **Tên**, **API Key**, **Quyền**, **Trạng thái**, **Sử dụng**, **Hết hạn** và **Thao tác**.

### Tạo API Key

| Bước | Cách thực hiện |
| --- | --- |
| 1 | Chọn <img src="https://api.iconify.design/lucide:plus.svg?color=%23ff3333" width="16" alt="" /> **(Tạo API Key)**. |
| 2 | Nhập **Tên API Key**. |
| 3 | Mở **Cài đặt nâng cao** nếu cần chọn **Quyền truy cập** cho key. |
| 4 | Chọn <img src="https://api.iconify.design/lucide:check.svg?color=%23ff3333" width="16" alt="" /> **(Tạo)** hoặc <img src="https://api.iconify.design/lucide:x.svg?color=%23ff3333" width="16" alt="" /> **(Hủy)**. |

Dùng <img src="https://api.iconify.design/lucide:search.svg?color=%23ff3333" width="16" alt="" /> **(Tìm kiếm)** để tra cứu và <img src="https://api.iconify.design/lucide:refresh-cw.svg?color=%23ff3333" width="16" alt="" /> **(Làm mới)** để cập nhật danh sách.

> **Cảnh báo:** API Key là thông tin xác thực. Không đưa key vào tài liệu công khai, ảnh chụp màn hình hoặc nội dung gửi cho người không có thẩm quyền.

## Cấu hình Model chạy ngầm

Tab **Model chạy ngầm** dùng để cấu hình model cho các tác vụ chạy ngầm và sắp xếp thứ tự ưu tiên Provider.

| Bước | Cách thực hiện |
| --- | --- |
| 1 | Kéo thả các thẻ trong **Cấu hình ưu tiên provider** để đổi thứ tự. |
| 2 | Chọn **Provider Type**. |
| 3 | Chọn **API Keys**. |
| 4 | Chọn **Models**. |
| 5 | Bật **Tùy chỉnh nâng cao** nếu cần mở các thiết lập bổ sung đang hiển thị trên giao diện. |
| 6 | Chọn **Lưu cài đặt**. |

## Cấu hình Agent Orchestrator

Trên giao diện, mở tab **Cấu hình Agent tổng**. Tab này cấu hình định tuyến model cho **Agent Orchestrator (RedAI - Agent Default)** trong Base hiện tại.

| Bước | Cách thực hiện |
| --- | --- |
| 1 | Kéo thả các thẻ trong **Cấu hình ưu tiên provider** để đổi thứ tự. |
| 2 | Chọn **Provider Type**. |
| 3 | Chọn **API Keys**. |
| 4 | Chọn **Models**. |
| 5 | Chọn **Lưu cài đặt**. |

> **Lưu ý:** Người dùng không chỉnh sửa Model trong cấu hình lõi của Agent Orchestrator tại module AI Agent. Tab **Cấu hình Agent tổng** chỉ dùng để thiết lập Provider, API Key và model định tuyến cho Agent này.

## Cấu hình Memory & Embedding

Mỗi **Embedding Item** gồm:

| Trường | Nội dung |
| --- | --- |
| **Provider** | Nhà cung cấp embedding. |
| **Model** | Model embedding được sử dụng. |
| **Nguồn key** | Nguồn API Key của cấu hình. |
| **Ưu tiên** | Thứ tự ưu tiên của Embedding Item. |

| Bước | Cách thực hiện |
| --- | --- |
| 1 | Chọn **Provider**, **Model**, **Nguồn key** và **Ưu tiên**. |
| 2 | Chọn **Thêm embedding item** nếu cần thêm cấu hình. |
| 3 | Chọn <img src="https://api.iconify.design/lucide:trash-2.svg?color=%23ff3333" width="16" alt="" /> **(Xóa)** tại item không còn dùng. |
| 4 | Chọn **Lưu cấu hình**. |

> **Lưu ý:** Cấu hình mới chỉ áp dụng cho memory được tạo sau thời điểm lưu. Memory cũ giữ nguyên embedding space đã có.

## Cấu hình RAG

Tab **Cấu hình RAG** gồm hai khu vực.

Cấu hình này xác định các model AI dùng khi xử lý tài liệu trong AI Drive, gồm phân tích nội dung và tạo Đồ thị tri thức (Knowledge Graph).

> **Lưu ý:** Thay đổi cấu hình RAG chỉ áp dụng cho tài liệu được xử lý mới.

### Cấu hình Embedding Model

| Bước | Cách thực hiện |
| --- | --- |
| 1 | Chọn **Nguồn API Key**. |
| 2 | Chọn **Lưu cấu hình**. |

### Quản lý LLM phân tích tài liệu

Danh sách hiển thị **Tên combo**, **Vai trò**, **Số model**, **Số lượng**, **Trạng thái** và **Thao tác**.

#### Tạo combo mới

| Bước | Cách thực hiện |
| --- | --- |
| 1 | Chọn <img src="https://api.iconify.design/lucide:plus.svg?color=%23ff3333" width="16" alt="" /> **(Tạo combo mới)**. |
| 2 | Nhập **Tên combo**, chọn **Vai trò** và nhập **Số lượng tối đa**. |
| 3 | Bật hoặc tắt **Hoạt động**. |
| 4 | Chọn model từ **Model hệ thống** hoặc **Model LLM tùy chỉnh**. |
| 5 | Kiểm tra **Model trong combo** và kéo thả để sắp xếp thứ tự ưu tiên. |
| 6 | Chọn **Tạo** hoặc **Hủy**. |

Dùng <img src="https://api.iconify.design/lucide:search.svg?color=%23ff3333" width="16" alt="" /> **(Tìm kiếm)** để tra cứu và <img src="https://api.iconify.design/lucide:refresh-cw.svg?color=%23ff3333" width="16" alt="" /> **(Làm mới)** để cập nhật danh sách. Dùng công tắc tại cột **Trạng thái** để bật hoặc tắt combo.

#### Sửa hoặc xóa combo

| Thao tác | Cách thực hiện |
| --- | --- |
| Sửa | Mở menu thao tác của combo, chọn **Chỉnh sửa**, cập nhật cấu hình rồi lưu. |
| Xóa | Mở menu thao tác, chọn **Xóa**, sau đó xác nhận. |

> **Cảnh báo:** Xóa combo tác động trực tiếp đến cấu hình RAG của Base và luôn có hộp thoại xác nhận.

## Cài đặt nâng cao

### Chọn giao diện

Tại **Theme**, chọn **Sáng**, **Tối** hoặc **Theo thiết bị**.

### Chọn múi giờ

Mở trường **Múi giờ** và chọn múi giờ cần áp dụng. Giao diện hiển thị thời gian hiện tại theo múi giờ đã chọn.

### Cấu hình xoay API Key LLM

**Cấu hình xoay API Key LLM** quy định hệ thống ưu tiên hoặc giới hạn nguồn API Key được dùng khi gọi LLM. Mở danh sách và chọn một trong năm chế độ:

| Chế độ | Cách hệ thống chọn API Key |
| --- | --- |
| **Tự động** | Tự xác định nguồn key theo loại Agent. Agent thông thường ưu tiên key người dùng; Agent **SYSTEM/SUPERVISOR** ưu tiên key hệ thống. |
| **Ưu tiên key người dùng** | Đặt key người dùng ở thứ tự ưu tiên trước key hệ thống. |
| **Chỉ dùng key người dùng** | Chỉ cho phép sử dụng key người dùng. |
| **Ưu tiên key hệ thống** | Đặt key hệ thống ở thứ tự ưu tiên trước key người dùng. |
| **Chỉ dùng key hệ thống** | Chỉ cho phép sử dụng key hệ thống. |

> **Lưu ý:** Thiết lập này chọn **nguồn API Key** giữa key người dùng và key hệ thống. Thứ tự Provider, API Key và model cụ thể được cấu hình tại các khu vực cấu hình model tương ứng.

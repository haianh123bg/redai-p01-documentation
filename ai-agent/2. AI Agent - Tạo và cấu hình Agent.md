## Mở form tạo Agent

1. Chọn đúng Workspace và Base sẽ lưu Agent.
2. Mở module **AI Agent**.
3. Chọn biểu tượng <img src="https://api.iconify.design/lucide:plus.svg?color=%23ff3333" width="16" alt="" /> **(Tạo Agent mới)** trên thanh công cụ.

## Thiết lập tên và ảnh đại diện

1. Nhập **Tên Agent**.
2. Chọn ảnh đại diện cho Agent nếu cần.
3. Chuyển đến khối **Danh sách ưu tiên** để cấu hình Model.

Tên Agent nên thể hiện đúng vai trò hoặc nghiệp vụ để dễ nhận biết trong danh sách và khi chọn Agent trong Chat Panel.

## Cấu hình Provider, Key LLM và Model

Mỗi cấu hình trong **Danh sách ưu tiên** gồm:

| Trường | Cách thiết lập |
| --- | --- |
| **Provider** | Chọn nhà cung cấp mô hình. Khi chọn RedAI, trường Key LLM hiển thị `RedAI (không cần key)`. |
| **Key LLM (API Key)** | Chọn API Key thuộc Provider tương ứng. |
| **Model** | Chọn Model Agent sẽ sử dụng. |
| **Tắt/Bật — Hiển thị thinking** | Tắt hoặc bật chế độ Thinking của Model tại cấu hình đang chọn. |

### Thêm và sắp xếp cấu hình ưu tiên

1. Thêm các cấu hình Provider, Key LLM và Model cần dùng.
2. Kéo thả từng thẻ cấu hình để sắp xếp thứ tự.
3. Kiểm tra nhãn `#1`, `#2`... trên từng thẻ.

Agent sử dụng cấu hình `#1` trước. Danh sách có thể kết hợp nhiều API Key, nhiều Model trong cùng một Provider và nhiều Provider khác nhau. Khi Provider hoặc API Key đang sử dụng gặp sự cố, bị gián đoạn hoặc bị giới hạn tần suất truy cập (rate limit), Agent tự động chuyển sang cấu hình dự phòng tiếp theo để duy trì hoạt động.

> **Lưu ý:** Chỉ chọn Key đã được tạo và còn hoạt động trong phạm vi Base hiện tại. Provider, API Key hoặc Model ngoài cấu hình RedAI mặc định phải được tích hợp và cấu hình trước trong Base hiện tại; chỉ những cấu hình khả dụng mới xuất hiện trong danh sách chọn.

## Viết và quản lý phiên bản Instruction

**Instruction** quy định Agent là ai, cần hoàn thành mục tiêu gì, được sử dụng tài nguyên nào và phải tuân theo giới hạn nào.

### Nội dung nên có

- Vai trò và đối tượng phục vụ.
- Mục tiêu và phạm vi nghiệp vụ.
- Trình tự xử lý chính.
- Quy tắc sử dụng Project, Skill, Tool, MCP hoặc Workflow.
- Cách xử lý khi thiếu dữ liệu hoặc ngoài phạm vi.
- Nguyên tắc bảo mật và những hành động không được phép.

Ô Instruction hỗ trợ tối đa **30.000 ký tự** theo giới hạn hiển thị trên giao diện.

### Tạo Instruction bằng AI

1. Tại khối **Instruction**, chọn biểu tượng <img src="https://api.iconify.design/lucide:sparkles.svg?color=%23ff3333" width="16" alt="" /> **(Tạo Instruction bằng AI)**.
2. Nhập yêu cầu vào ô **Nhập yêu cầu để AI tạo instruction cho Agent...**. Nêu rõ vai trò, mục tiêu, đối tượng phục vụ, quy trình, tài nguyên được phép dùng và các giới hạn cần tuân theo.
3. Chọn nút **Gửi yêu cầu** trong hộp thoại.
4. Kiểm tra và chỉnh sửa nội dung Instruction do AI tạo trước khi lưu Agent hoặc tạo phiên bản mới.

### Tạo phiên bản Instruction

1. Nhập nội dung vào ô **Instruction**.
2. Chọn biểu tượng <img src="https://api.iconify.design/lucide:plus.svg?color=%23ff3333" width="16" alt="" /> **(Add Version)** để tạo thêm phiên bản.
3. Chọn phiên bản cần sử dụng.
4. Kiểm tra nhãn **Main** trên phiên bản đang được đặt làm phiên bản chính.

Việc tách phiên bản giúp cập nhật Instruction mà vẫn nhận biết được nội dung đang dùng làm bản chính.

## Cấu hình Thông tin cá nhân

1. Chọn biểu tượng <img src="https://api.iconify.design/lucide:pencil.svg?color=%23ff3333" width="16" alt="" /> **(Chỉnh sửa)** tại dòng **Thông tin cá nhân**.
2. Điền các trường cần sử dụng:

| Trường | Nội dung |
| --- | --- |
| **Mô tả nhận diện** | Mô tả chuyên môn, vai trò và cách Agent thể hiện khi giao tiếp. Tối đa 3.000 ký tự. |
| **Ngày sinh** | Ngày sinh dùng cho hồ sơ nhận diện của Agent. |
| **Giới tính** | Giới tính được chọn cho Agent. |
| **Trình độ học vấn** | Trình độ phù hợp với vai trò Agent. |
| **Ngôn ngữ** | Một hoặc nhiều ngôn ngữ Agent sử dụng. |
| **Quốc gia** | Quốc gia hoặc thị trường hoạt động. |
| **Chức vụ** | Chức danh chuyên môn của Agent. |
| **Kỹ năng** | Nhập từng kỹ năng và nhấn Enter; giao diện hỗ trợ tối đa 20 mục. |
| **Tính cách** | Nhập từng đặc điểm và nhấn Enter; giao diện hỗ trợ tối đa 20 mục. |

3. Chọn biểu tượng <img src="https://api.iconify.design/lucide:check.svg?color=%23ff3333" width="16" alt="" /> **(Lưu)** ở cuối panel.
4. Chọn <img src="https://api.iconify.design/lucide:x.svg?color=%23ff3333" width="16" alt="" /> **(Đóng)** nếu không tiếp tục chỉnh sửa.

## Lưu Agent

1. Kiểm tra tên, cấu hình ưu tiên, Instruction và Thông tin cá nhân.
2. Chọn biểu tượng <img src="https://api.iconify.design/lucide:check.svg?color=%23ff3333" width="16" alt="" /> **(Lưu Agent)** ở góc trên bên phải.
3. Chọn <img src="https://api.iconify.design/lucide:x.svg?color=%23ff3333" width="16" alt="" /> **(Hủy/Đóng)** nếu không muốn lưu thay đổi hiện tại.

Sau khi lưu, Agent xuất hiện trong danh sách của Base đang chọn.

## Cập nhật Agent

1. Mở module **AI Agent**.
2. Chọn Agent cần cập nhật để mở màn hình **Chỉnh sửa Agent**.
3. Chỉnh sửa các cấu hình cần thiết.
4. Chọn <img src="https://api.iconify.design/lucide:check.svg?color=%23ff3333" width="16" alt="" /> **(Lưu Agent)**.

Nếu thay đổi Instruction, hãy kiểm tra đúng phiên bản mang nhãn **Main** trước khi lưu.

## Tạo Agent qua Chat Panel hoặc RedHub

### Yêu cầu Agent Orchestrator tạo Agent

1. Mở **Chat Panel** và chọn **Agent Orchestrator (RedAI - Agent Default)**, có tên hiển thị là **RedAI**.
2. Mô tả Agent cần tạo, gồm vai trò, mục tiêu, đối tượng phục vụ, nghiệp vụ và các năng lực cần sử dụng.
3. Gửi yêu cầu để Agent Orchestrator tạo Agent theo nội dung đã cung cấp.

### Tạo Agent từ tài nguyên trên RedHub

1. Trong module **AI Agent**, chọn biểu tượng <img src="https://api.iconify.design/lucide:shopping-cart.svg?color=%23ff3333" width="16" alt="" /> **(Mở RedHub)**.
2. Tìm và mở tài nguyên thuộc loại **AI Agent**.
3. Nhận phiên bản phù hợp vào Base hiện tại.
4. Mở module **AI Agent**, tạo Agent từ mẫu đã nhận và điều chỉnh cấu hình theo nhu cầu sử dụng.

Quy trình thao tác với mẫu Agent được trình bày tại bài **5. AI Agent - Quản lý Agent và Template**. Quy trình khám phá và nhận tài nguyên được trình bày tại bài **2. Module RedHub - Khám phá và nhận tài nguyên** trong bộ tài liệu Module RedHub.

## Tối ưu Agent đã có

Người dùng có thể chọn một trong hai cách:

- Yêu cầu **Agent Orchestrator (RedAI - Agent Default)** đánh giá và tối ưu Agent.
- Trao đổi trực tiếp với chính Agent cần tối ưu và yêu cầu Agent tự đánh giá, đề xuất hoặc thực hiện tối ưu cấu hình của mình.

Khi gửi yêu cầu tối ưu, cần nêu rõ mục tiêu, vấn đề hiện tại và kết quả mong muốn để Agent xác định đúng phần cần điều chỉnh.

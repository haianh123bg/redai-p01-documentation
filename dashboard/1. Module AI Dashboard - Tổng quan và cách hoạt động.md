## Các thành phần chính

| Thành phần | Vai trò |
| --- | --- |
| Trang | Không gian hiển thị một Dashboard. Một Base có thể có nhiều trang. |
| Nguồn dữ liệu | Các API Tool cá nhân hoặc hệ thống được chọn để Agent đọc và sử dụng khi tạo Dashboard. |
| Chat Panel | Nơi gửi yêu cầu để Agent tạo mới hoặc chỉnh sửa Dashboard đang mở. |
| Mẫu | Bố cục Dashboard có sẵn để xem trước và áp dụng. |
| Version | Bản lưu trạng thái của Dashboard tại một thời điểm; có thể dùng để khôi phục hoặc làm nguồn phát hành lên RedHub. |
| Liên kết chia sẻ | Liên kết công khai có thể cấu hình mật khẩu, thời gian hết hạn và quyền sử dụng nội dung. |

## Hai cách tạo Dashboard

### Tạo bằng Agent trong Chat Panel

Người dùng có thể yêu cầu một trong hai loại Agent:

- **Agent Orchestrator (RedAI - Agent Default)**.
- Agent do người dùng tạo và đã được gắn Skill hệ thống **RedAI - Module - AI Dashboard**.

Agent có thể tạo trang mới, xây dựng Dashboard từ nguồn dữ liệu đã chọn hoặc chỉnh sửa Dashboard đang mở theo yêu cầu. Khả năng này hiện được hướng dẫn trong phạm vi Chat Panel.

### Tạo từ mẫu

Người dùng mở **Danh sách mẫu**, xem trước mẫu phù hợp, chọn mẫu rồi xác nhận. Sau đó có thể chọn nguồn dữ liệu và yêu cầu Agent điều chỉnh nội dung theo nhu cầu.

## Luồng hoạt động

1. Chọn đúng Base.
2. Tạo trang mới hoặc mở một trang hiện có.
3. Chọn nguồn dữ liệu nếu Dashboard cần sử dụng API Tool.
4. Yêu cầu Agent tạo hoặc chỉnh sửa Dashboard, hoặc áp dụng một mẫu có sẵn.
5. Tạo Version khi cần lưu một mốc trạng thái.
6. Chia sẻ Dashboard qua liên kết hoặc dùng Version làm nguồn phát hành lên RedHub.

## Lưu ý

- Agent chỉ truy cập các nguồn dữ liệu và tài nguyên phù hợp trong Base hiện tại.
- **Tải Lại** chỉ cập nhật Dashboard đang mở; nút tải lại trong **Quản Lý Trang** dùng để cập nhật danh sách trang.
- Phát hành AI Dashboard lên RedHub sử dụng **Version**, không sử dụng Template hoặc Snapshot.

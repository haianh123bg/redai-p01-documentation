## Mở danh sách Version

| Bước | Thao tác |
| --- | --- |
| 1 | Mở Dashboard cần quản lý. |
| 2 | Chọn biểu tượng <img src="https://api.iconify.design/lucide:history.svg?color=%23ff3333" width="16" alt="" /> **(Versions)** trên thanh công cụ. |
| 3 | Panel **Danh sách phiên bản – [Tên Dashboard]** hiển thị các Version hiện có. |

Mỗi dòng hiển thị số phiên bản, tên, thời gian tạo và số lượng Component.

## Tạo Version

| Bước | Thao tác |
| --- | --- |
| 1 | Trong panel **Danh sách phiên bản**, chọn biểu tượng <img src="https://api.iconify.design/lucide:plus.svg?color=%23ff3333" width="16" alt="" /> **(Tạo phiên bản)**. |
| 2 | Nhập tên Version. |
| 3 | Chọn <img src="https://api.iconify.design/lucide:plus.svg?color=%23ff3333" width="16" alt="" /> **(Tạo phiên bản)** để lưu trạng thái Dashboard hiện tại. |

Chọn <img src="https://api.iconify.design/lucide:refresh-cw.svg?color=%23ff3333" width="16" alt="" /> **(Tải lại)** trong panel nếu cần cập nhật danh sách.

## Khôi phục Version

| Bước | Thao tác |
| --- | --- |
| 1 | Tìm Version cần khôi phục. |
| 2 | Chọn biểu tượng <img src="https://api.iconify.design/lucide:rotate-ccw.svg?color=%23ff3333" width="16" alt="" /> **(Khôi phục)** tại Version. |
| 3 | Đọc panel **Xác nhận khôi phục version**. |
| 4 | Chọn biểu tượng <img src="https://api.iconify.design/lucide:check.svg?color=%23ff3333" width="16" alt="" /> **(Xác nhận khôi phục)**. |

Hệ thống tự tạo một checkpoint của trạng thái hiện tại trước khi khôi phục Dashboard về Version đã chọn.

## Xóa Version

| Bước | Thao tác |
| --- | --- |
| 1 | Chọn biểu tượng <img src="https://api.iconify.design/lucide:trash-2.svg?color=%23ff3333" width="16" alt="" /> **(Xóa)** tại Version cần xóa. |
| 2 | Đọc hộp xác nhận. |
| 3 | Xác nhận xóa Version. |

> **Cảnh báo:** Không xóa Version đang cần dùng để khôi phục hoặc phát hành lên RedHub.

## Phát hành AI Dashboard lên RedHub

AI Dashboard sử dụng **Version** làm nguồn phát hành.

1. Hoàn thiện Dashboard và tạo Version.
2. Mở module **RedHub** và vào **Tài nguyên phát hành**.
3. Tạo tài nguyên mới, chọn loại **AI Dashboard**.
4. Tại phần nguồn dữ liệu, chọn Version cần phát hành.
5. Hoàn thiện thông tin tài nguyên và gửi duyệt theo quy trình của RedHub.

Xem hướng dẫn chi tiết tại **4. Module RedHub - Phát hành tài nguyên.md**.

> **Lưu ý:** RedHub chỉ hiển thị Version AI Dashboard thuộc Base đang chọn.

## Mở khu vực tài khoản

| Bước | Cách thực hiện |
| --- | --- |
| 1 | Chọn ảnh đại diện ở góc trên bên phải. |
| 2 | Chọn **Hồ sơ**, **Cài đặt** hoặc **Lịch sử sử dụng** theo nội dung cần quản lý. |

Menu tài khoản còn có các mục **Trợ giúp**, **Ngôn ngữ**, **Giao diện**, **Affiliate**, **Bot hướng dẫn** và **Đăng xuất**.

## Phân biệt phạm vi dữ liệu

| Khu vực | Phạm vi áp dụng | Nội dung chính |
| --- | --- | --- |
| **Hồ sơ** | Tài khoản đang đăng nhập | Thông tin cá nhân, bảo mật, doanh nghiệp, ngân hàng, hợp đồng, bộ nhớ cá nhân, lịch sử đăng nhập và tùy chỉnh email. |
| **Cài đặt** | Base đang chọn | Coupon, API Key, model chạy ngầm, cấu hình Agent Orchestrator, Memory & Embedding, từ khóa Chat, RAG và cài đặt nâng cao. |
| **Lịch sử sử dụng** | Base đang chọn | Chi phí, R-Point, dung lượng, mức sử dụng tính năng, lịch sử Agent/AI Studio, model và gói dịch vụ. |

> **Lưu ý:** Đổi Base không làm thay đổi dữ liệu trong **Hồ sơ**, nhưng làm thay đổi dữ liệu hiển thị tại **Cài đặt** và **Lịch sử sử dụng**. Luôn kiểm tra đúng Base trước khi cấu hình hoặc đối chiếu mức sử dụng.

## Các nhóm trong Hồ sơ

| Nhóm | Nội dung |
| --- | --- |
| **Thông tin cá nhân** | Họ tên, địa chỉ, giới tính, ngày sinh, email và số điện thoại. |
| **Bảo mật** | Xác thực qua SMS, Email, Google Authenticator và đổi mật khẩu. |
| **Thông tin doanh nghiệp** | Chuyển từ tài khoản cá nhân sang tài khoản doanh nghiệp. |
| **Thông tin ngân hàng** | Ngân hàng, số tài khoản, chi nhánh và chủ tài khoản. |
| **Quản lý hợp đồng** | Hợp đồng nguyên tắc và Hợp đồng Affiliate. |
| **Bộ nhớ cá nhân** | Xem và quản lý memory dưới dạng Graph. |
| **Lịch sử đăng nhập** | Phương thức xác thực, trạng thái, IP, User Agent và thời gian đăng nhập. |
| **Tùy chỉnh email** | Bật hoặc tắt từng nhóm email thông báo. |

## Các tab trong Cài đặt

Phía trên các tab là khu vực **Nhận khuyến mãi**, dùng để nhập coupon và chọn **Áp dụng mã**.

| Tab | Chức năng |
| --- | --- |
| **API Key** | Tạo và quản lý API Key trong Base. |
| **Model chạy ngầm** | Chọn Provider, API Key, model và thứ tự ưu tiên cho các tác vụ chạy ngầm. |
| **Cấu hình Agent tổng** | Cấu hình Provider, API Key và model định tuyến cho **Agent Orchestrator (RedAI - Agent Default)** trong Base hiện tại. |
| **Memory & Embedding** | Chọn Provider, model embedding, nguồn key và độ ưu tiên. |
| **Từ khóa Chat** | Gắn một hoặc nhiều từ khóa với Router đích. |
| **Cấu hình RAG** | Chọn nguồn API Key cho Embedding Model và quản lý combo LLM phân tích tài liệu. |
| **Cài đặt nâng cao** | Chọn giao diện, múi giờ và cơ chế xoay API Key LLM. |

> **Lưu ý về thuật ngữ:** **Cấu hình Agent tổng** là nhãn đang hiển thị trên giao diện. Trong tài liệu, Agent này được gọi thống nhất là **Agent Orchestrator (RedAI - Agent Default)**.

## Nội dung trong Lịch sử sử dụng

Trang **Lịch sử sử dụng** tổng hợp dữ liệu của Base đang chọn, gồm:

- Tổng hợp số tiền nạp.
- Dung lượng lưu trữ đám mây.
- Lịch sử mua gói R-Point.
- Lịch sử chi tiêu trợ lý.
- Lịch sử chi tiết AI Studio.
- Lưu lượng sử dụng tính năng.
- Danh sách model và đơn giá Input/Output.
- Lịch sử mua gói dịch vụ.

Chọn tiêu đề của từng khu vực để mở hoặc thu gọn dữ liệu.

## Thao tác trên thẻ Agent

| Biểu tượng | Chức năng |
| --- | --- |
| <img src="https://api.iconify.design/lucide:power.svg?color=%23ff3333" width="16" alt="" /> **(Bật/Tắt Agent)** | Bật hoặc dừng hoạt động của Agent. |
| <img src="https://api.iconify.design/lucide:copy.svg?color=%23ff3333" width="16" alt="" /> **(Nhân bản)** | Tạo một Agent mới từ Agent hiện tại. |

Chọn thẻ Agent để mở màn hình **Chỉnh sửa Agent**.

> **Cảnh báo:** Xóa Agent là thao tác vĩnh viễn và không thể khôi phục. Hệ thống hiển thị hộp xác nhận trước khi xóa.

## Nhân bản Agent

1. Tại thẻ Agent nguồn, chọn <img src="https://api.iconify.design/lucide:copy.svg?color=%23ff3333" width="16" alt="" /> **(Nhân bản)**.
2. Chọn các nhóm tài nguyên muốn giữ lại cho bản sao nếu panel lựa chọn được hiển thị.
3. Xác nhận thao tác.
4. Mở Agent mới và cập nhật tên hoặc cấu hình theo nhu cầu.

Agent được nhân bản trở thành một Agent mới trong Base hiện tại.

## Tạo Agent Template

1. Tại thẻ Agent nguồn, chọn <img src="https://api.iconify.design/lucide:square-dashed.svg?color=%23ff3333" width="16" alt="" /> **(Tạo Agent Template)**.
2. Điền thông tin Template theo form.
3. Bật hoặc tắt các nhóm dữ liệu cần đưa vào Template:

| Nhóm | Tài nguyên có thể chọn |
| --- | --- |
| **Tài nguyên Project** | Knowledge files, Media, URLs, Products, Tables. |
| **Tài nguyên Skill** | Docs, Tools, MCPs, Workflows. |

4. Chọn biểu tượng <img src="https://api.iconify.design/lucide:check.svg?color=%23ff3333" width="16" alt="" /> **(Lưu)** ở cuối panel để tạo Template.

Chỉ những nhóm đang bật mới được đưa vào Template.

## Mở danh sách Mẫu Agent

1. Tại thanh công cụ của module AI Agent, chọn <img src="https://api.iconify.design/lucide:square-dashed.svg?color=%23ff3333" width="16" alt="" /> **(Quản lý Templates)**.
2. Màn hình **Mẫu Agent** hiển thị các cột:

- Tên Template.
- Mô tả.
- Version.
- Kích thước.
- Ngày tạo.
- Thao tác.

Các biểu tượng trên thanh công cụ gồm <img src="https://api.iconify.design/lucide:search.svg?color=%23ff3333" width="16" alt="" /> **(Tìm kiếm)**, <img src="https://api.iconify.design/lucide:funnel.svg?color=%23ff3333" width="16" alt="" /> **(Bộ lọc)** và <img src="https://api.iconify.design/lucide:refresh-cw.svg?color=%23ff3333" width="16" alt="" /> **(Tải lại dữ liệu)**.

## Tạo Agent từ Template

1. Tại dòng Template, chọn <img src="https://api.iconify.design/lucide:ellipsis-vertical.svg?color=%23ff3333" width="16" alt="" /> **(Thao tác)**.
2. Chọn <img src="https://api.iconify.design/lucide:plus.svg?color=%23ff3333" width="16" alt="" /> **(Tạo Agent mới)**.
3. Trong panel **Tạo Agent từ Template**, kiểm tra Template và Version.
4. Nhập **Tên Agent mới**.
5. Chọn <img src="https://api.iconify.design/lucide:check.svg?color=%23ff3333" width="16" alt="" /> **(Lưu Agent)**.

Agent mới được tạo trong Base đang chọn. Mở Agent để kiểm tra và bổ sung các cấu hình cần thiết trước khi bật sử dụng.

## Sửa Template

1. Tại dòng Template, chọn <img src="https://api.iconify.design/lucide:ellipsis-vertical.svg?color=%23ff3333" width="16" alt="" /> **(Thao tác)**.
2. Chọn biểu tượng <img src="https://api.iconify.design/lucide:pencil.svg?color=%23ff3333" width="16" alt="" /> **(Sửa)**.
3. Trong panel **Chỉnh sửa Template**, cập nhật:

- Tên Template.
- Mô tả.
- Version.

4. Chọn <img src="https://api.iconify.design/lucide:check.svg?color=%23ff3333" width="16" alt="" /> **(Lưu)** hoặc <img src="https://api.iconify.design/lucide:x.svg?color=%23ff3333" width="16" alt="" /> **(Hủy)**.

## Nhận Template Agent từ RedHub

1. Chọn <img src="https://api.iconify.design/lucide:shopping-cart.svg?color=%23ff3333" width="16" alt="" /> **(Mở RedHub)** trên thanh công cụ.
2. Tìm tài nguyên loại **AI Agent**.
3. Mở chi tiết và nhận phiên bản cần sử dụng.
4. Tài nguyên được đưa vào module tương ứng trong Base hiện tại và được ghi lại tại **Lịch sử đã nhận**.

Quy trình tìm kiếm, nhận phiên bản và quản lý lịch sử được hướng dẫn tại:

- `2. Module RedHub - Khám phá và nhận tài nguyên.md` trong bộ tài liệu **Module RedHub**.

## Nhân bản Skill

Có thể nhân bản Skill hệ thống hoặc Skill User.

| Bước | Cách thực hiện |
| --- | --- |
| 1 | Di chuột vào thẻ Skill và nhấn biểu tượng <img src="https://api.iconify.design/lucide:copy.svg?color=%23ff3333" width="16" alt="" /> **(Nhân bản)**. |
| 2 | Trong bảng **Nhân bản Skill**, bật hoặc tắt **Tài liệu (Docs)**, **Công cụ (Tools)**, **MCP (Model Context Protocol)** và **Kịch bản (Workflows)** để chọn tài nguyên giữ lại. |
| 3 | Nhấn biểu tượng <img src="https://api.iconify.design/lucide:copy.svg?color=%23ff3333" width="16" alt="" /> **(Nhân bản)** ở cuối bảng. |

Hệ thống tạo một Skill User mới; Skill nguồn không bị thay đổi.

## Xóa Skill User

> **Cảnh báo:** Xóa Skill sẽ xóa Skill User đang chọn. Hệ thống hiển thị bảng **Xóa skill** để xác nhận trước khi thực hiện.

| Bước | Cách thực hiện |
| --- | --- |
| 1 | Di chuột vào thẻ Skill User và nhấn biểu tượng <img src="https://api.iconify.design/lucide:trash-2.svg?color=%23ff3333" width="16" alt="" /> **(Xóa)**. |
| 2 | Trong bảng **Xóa skill**, nhấn biểu tượng <img src="https://api.iconify.design/lucide:trash-2.svg?color=%23ff3333" width="16" alt="" /> **(Xóa)** để xác nhận hoặc <img src="https://api.iconify.design/lucide:x.svg?color=%23ff3333" width="16" alt="" /> **(Hủy)** để đóng. |

## Quản lý Docs trong Skill

Mở thẻ Skill User và chọn tab **Docs**.

### Thêm Doc

| Cách thêm | Thao tác |
| --- | --- |
| Tải tệp Markdown | Nhấn biểu tượng <img src="https://api.iconify.design/lucide:upload.svg?color=%23ff3333" width="16" alt="" /> **(Import markdown file)**, chọn tệp Markdown trên thiết bị rồi xác nhận. |
| Chọn Doc hiện có | Nhấn biểu tượng <img src="https://api.iconify.design/lucide:files.svg?color=%23ff3333" width="16" alt="" /> **(Chọn Doc hiện có)** nằm giữa **Import markdown file** và **Create new doc**; tại màn hình **Tạo mới**, chọn tab **Docs**, đánh dấu Doc cần thêm rồi nhấn <img src="https://api.iconify.design/lucide:check.svg?color=%23ff3333" width="16" alt="" /> **(Lưu)**. |
| Tạo Doc mới | Nhấn biểu tượng <img src="https://api.iconify.design/lucide:plus.svg?color=%23ff3333" width="16" alt="" /> **(Create new doc)**, nhập **Path** và **Content**, sau đó nhấn <img src="https://api.iconify.design/lucide:check.svg?color=%23ff3333" width="16" alt="" /> **(Lưu)**. |

### Sửa Doc

| Bước | Cách thực hiện |
| --- | --- |
| 1 | Tại thẻ Doc, nhấn biểu tượng <img src="https://api.iconify.design/lucide:pencil.svg?color=%23ff3333" width="16" alt="" /> **(Sửa)** để mở bảng **Edit doc**. |
| 2 | Cập nhật **Path** hoặc **Content**. |
| 3 | Nhấn biểu tượng <img src="https://api.iconify.design/lucide:check.svg?color=%23ff3333" width="16" alt="" /> **(Lưu)**. |

### Xóa một hoặc nhiều Docs

> **Cảnh báo:** Thao tác này xóa các Docs đã chọn. Nếu không chọn tài nguyên nào, nút thùng rác trên thanh công cụ chi tiết có chức năng **Xóa skill**.

| Bước | Cách thực hiện |
| --- | --- |
| 1 | Đánh dấu ô chọn của một hoặc nhiều Docs. |
| 2 | Nhấn biểu tượng <img src="https://api.iconify.design/lucide:trash-2.svg?color=%23ff3333" width="16" alt="" /> **(Xóa)** trên thanh công cụ phía trên màn hình. |
| 3 | Trong bảng **Xác nhận xóa**, nhấn biểu tượng <img src="https://api.iconify.design/lucide:trash-2.svg?color=%23ff3333" width="16" alt="" /> **(Xóa)** để xác nhận. |

## Liên kết Tools, MCPs và Workflows

| Bước | Cách thực hiện |
| --- | --- |
| 1 | Mở Skill User và chọn tab **Tools**, **MCPs** hoặc **Workflows**. |
| 2 | Nhấn biểu tượng <img src="https://api.iconify.design/lucide:plus.svg?color=%23ff3333" width="16" alt="" /> **(Tạo mới)**. |
| 3 | Chọn một hoặc nhiều tài nguyên cần liên kết. Với Tools, có thể chọn nhóm Project/API trước khi chọn Tool. |
| 4 | Nhấn biểu tượng <img src="https://api.iconify.design/lucide:check.svg?color=%23ff3333" width="16" alt="" /> **(Lưu)**. |

> **Lưu ý đối với Workflow:** Agent chỉ có thể kích hoạt Workflow qua Skill khi node đầu tiên là **Kích hoạt Click**, **Kích hoạt Hệ thống Tùy chỉnh** hoặc **Kích hoạt Tin nhắn**.

## Xóa liên kết Tools, MCPs hoặc Workflows khỏi Skill

| Bước | Cách thực hiện |
| --- | --- |
| 1 | Mở tab **Tools**, **MCPs** hoặc **Workflows**. |
| 2 | Đánh dấu một hoặc nhiều tài nguyên cần xóa liên kết. |
| 3 | Nhấn biểu tượng <img src="https://api.iconify.design/lucide:trash-2.svg?color=%23ff3333" width="16" alt="" /> **(Xóa)** trên thanh công cụ phía trên màn hình. |
| 4 | Xác nhận thao tác. |

Thao tác **Xóa** tại đây chỉ xóa liên kết với Skill; Tool, MCP hoặc Workflow gốc vẫn còn trong module tương ứng.

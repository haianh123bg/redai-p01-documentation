## Khả năng chính

| Nhóm năng lực | Khả năng của Agent Orchestrator |
| --- | --- |
| **Giải đáp và hướng dẫn** | Giải thích tính năng, kiến trúc, thuật ngữ và hướng dẫn thao tác trên RedAI. |
| **Phân tích và lập kế hoạch** | Phân tích yêu cầu, chia nhỏ công việc, đề xuất phương án triển khai và xác định module hoặc tài nguyên cần dùng. |
| **Thao tác trên nền tảng** | Thực hiện hầu hết thao tác được RedAI hỗ trợ trong phạm vi quyền hiện có, thay vì người dùng phải mở từng module và cấu hình thủ công. |
| **Tạo và cấu hình tài nguyên** | Tạo hoặc cấu hình các đối tượng như Agent, Skill, nhiệm vụ Calendar, Template và những tài nguyên khác được nền tảng hỗ trợ. |
| **Cập nhật và tối ưu** | Phân tích, chỉnh sửa và tối ưu tài nguyên hoặc cấu hình đã có theo mục tiêu của người dùng. |
| **Điều phối công việc nhiều bước** | Lập danh sách Todo, thực hiện các bước phụ thuộc nhau và điều phối tác vụ cần thiết để hoàn thành mục tiêu. |
| **Làm việc với dữ liệu và tài nguyên** | Sử dụng dữ liệu, file, Tool, Skill và tài nguyên thuộc Base hiện tại khi được cấp quyền truy cập. |
| **Tạo nội dung và đầu ra nghiệp vụ** | Xây dựng tài liệu, kế hoạch, nội dung, mẫu marketing và các đầu ra phù hợp với yêu cầu được cung cấp. |

Các khả năng dưới đây là ví dụ tiêu biểu, không phải danh sách giới hạn:

- Tạo Agent mới hoặc tối ưu Agent đã có.
- Tạo Skill theo mục tiêu, quy trình và tài nguyên được mô tả.
- Tạo sự kiện hoặc nhiệm vụ Calendar; cấu hình đồng thời hành động Agent, Workflow và Thông báo.
- Tạo Template marketing, mẫu nội dung hoặc tài liệu theo yêu cầu.
- Giải đáp thắc mắc, đề xuất cách triển khai và thực hiện công việc trên các module của RedAI.

## Chọn Agent Orchestrator

| Bước | Cách thực hiện |
| --- | --- |
| 1 | Chọn **biểu tượng RedAI** trên thanh điều hướng bên trái để mở Chat Panel. |
| 2 | Chọn **tên Agent và mũi tên xuống** ở đầu Chat Panel. |
| 3 | Chọn Agent có tên hiển thị **RedAI**. |

## Cấu hình model cho Agent Orchestrator

Khu vực **Cấu hình Agent tổng RedAI** dùng để định tuyến model cho Agent Orchestrator theo Workspace và Base hiện tại.

| Bước | Cách thực hiện |
| --- | --- |
| 1 | Kiểm tra đúng Workspace và Base cần áp dụng cấu hình. |
| 2 | Mở menu tài khoản ở góc trên bên phải và chọn **Cài đặt**. |
| 3 | Chọn tab **Cấu hình Agent tổng**. |
| 4 | Tại **Cấu hình ưu tiên provider**, kéo thả các provider để sắp xếp thứ tự ưu tiên. |
| 5 | Tại phần cấu hình của từng provider, chọn **Provider Type**, **API Keys** và **Model ID**. |
| 6 | Chọn **Lưu cài đặt**. |

> [!NOTE]
> Cấu hình model thay đổi theo Workspace và Base hiện tại. Đây không phải quyền chỉnh sửa Instruction hệ thống, kênh giao tiếp hoặc cấu hình lõi của Agent Orchestrator.

## Gửi yêu cầu

| Bước | Cách thực hiện |
| --- | --- |
| 1 | Chọn <img src="https://api.iconify.design/lucide:shield-check.svg?color=%23ff3333" width="16" alt="" /> **(Hỏi trước/Toàn quyền)** và chọn chế độ thực thi. |
| 2 | Mô tả rõ mục tiêu, kết quả cần tạo và các điều kiện phải tuân thủ. |
| 3 | Nếu cần tài nguyên, gõ `@` rồi chọn Tool, Skill, File hoặc ảnh thuộc Base hiện tại. |
| 4 | Nếu có Prompt mẫu, gõ `/` rồi chọn Prompt cần dùng. |
| 5 | Chọn <img src="https://api.iconify.design/lucide:send.svg?color=%23ff3333" width="16" alt="" /> **(Gửi)**. |

Ví dụ:

- `Tạo một Agent chăm sóc khách hàng cho Fanpage và đề xuất cấu hình cần thiết.`
- `Tối ưu Agent đang chọn để trả lời khách hàng ngắn gọn và đúng chính sách.`
- `Tạo Skill chuẩn hóa bài viết sản phẩm theo cấu trúc tôi cung cấp.`
- `Tạo nhiệm vụ Calendar chạy Workflow lúc 08:00 hằng ngày và gửi thông báo khi thực thi thất bại.`
- `Tạo Template marketing cho chiến dịch ra mắt sản phẩm mới.`

> [!CAUTION]
> Khi dùng **Toàn quyền**, Agent Orchestrator có thể thực hiện hành động trong phạm vi quyền của người dùng. Với yêu cầu có thể tạo, sửa hoặc xóa dữ liệu, dùng **Hỏi trước** nếu muốn xác nhận từng hành động.

## Phạm vi hoạt động

- Agent Orchestrator chỉ tương tác với người dùng trong **Chat Panel**, bao gồm Chat bằng văn bản và Voice Chat.
- Agent Orchestrator không hoạt động như một Agent tại các kênh đầu ra.
- Agent Orchestrator làm việc trong Base đang chọn.
- Dữ liệu và tài nguyên Agent có thể sử dụng phụ thuộc vào Base hiện tại và quyền của người dùng.
- Agent Orchestrator không tự truy cập tài nguyên thuộc Base khác.
- Khi chuyển Base, phạm vi dữ liệu và tài nguyên cũng thay đổi.

Nếu Agent Orchestrator không tìm thấy tài nguyên, hãy kiểm tra lại Workspace, Base và tài nguyên đã gọi bằng `@`.

## Sử dụng Voice Chat

| Bước | Cách thực hiện |
| --- | --- |
| 1 | Chọn Agent có tên hiển thị **RedAI**. |
| 2 | Chọn <img src="https://api.iconify.design/lucide:phone-call.svg?color=%23ff3333" width="16" alt="" /> **(Voice Chat)** trên thanh công cụ phía trên. |
| 3 | Cho phép trình duyệt sử dụng micro nếu được hỏi. |
| 4 | Trao đổi bằng giọng nói với Agent Orchestrator. |
| 5 | Chọn **nút kết thúc cuộc gọi** khi hoàn tất. |

Agent Orchestrator hỗ trợ Voice Chat trực tiếp; người dùng không cần tự cấu hình giọng nói cho Agent hệ thống này.

## Mở Thư viện Prompt

| Bước | Cách thực hiện |
| --- | --- |
| 1 | Chọn <img src="https://api.iconify.design/lucide:message-square.svg?color=%23ff3333" width="16" alt="" /> **(Thư viện Prompt)** trên thanh công cụ phía dưới Chat Panel. |
| 2 | Khu vực **Danh mục** hiển thị bên trái; danh sách **Thư viện Prompt** hiển thị bên phải. |

## Quản lý danh mục

| Thao tác | Cách thực hiện |
| --- | --- |
| Tạo danh mục | Chọn <img src="https://api.iconify.design/lucide:plus.svg?color=%23ff3333" width="16" alt="" /> **(Tạo danh mục)** cạnh tiêu đề **Danh mục**, nhập tên rồi chọn <img src="https://api.iconify.design/lucide:check.svg?color=%23ff3333" width="16" alt="" /> **(Lưu)**. |
| Xem toàn bộ Prompt | Chọn **Tất cả Prompt**. |
| Xem Prompt theo danh mục | Chọn tên danh mục cần xem. |

## Tạo Prompt

| Bước | Cách thực hiện |
| --- | --- |
| 1 | Chọn <img src="https://api.iconify.design/lucide:sparkles.svg?color=%23ff3333" width="16" alt="" /> **(Tạo Prompt)** trên thanh công cụ của **Thư viện Prompt**. |
| 2 | Nhập **Tên Prompt** và **Phím tắt**. Phím tắt được gọi trong Chat Panel bằng ký tự `/`. |
| 3 | Chọn **Danh mục** nếu cần. |
| 4 | Nhập **Mô tả** và **Nội dung Prompt**. |
| 5 | Nếu Prompt cần biến, chèn biến theo dạng `{{ten_bien}}` rồi cấu hình biến theo mục tiếp theo. |
| 6 | Chọn <img src="https://api.iconify.design/lucide:check.svg?color=%23ff3333" width="16" alt="" /> **(Lưu)** ở cuối màn hình. |

## Cấu hình biến

| Bước | Cách thực hiện |
| --- | --- |
| 1 | Trong form tạo hoặc chỉnh sửa Prompt, chọn <img src="https://api.iconify.design/lucide:plus.svg?color=%23ff3333" width="16" alt="" /> **(Thêm biến)** tại khu vực **Cấu hình biến**. |
| 2 | Khai báo đúng tên biến đã dùng trong nội dung Prompt, ví dụ `{{name}}`. |
| 3 | Nhập **Nhãn hiển thị** và **Giá trị mặc định** nếu cần. |
| 4 | Chọn **Bắt buộc** nếu người dùng phải nhập giá trị trước khi sử dụng Prompt. |
| 5 | Chọn biểu tượng <img src="https://api.iconify.design/lucide:check.svg?color=%23ff3333" width="16" alt="" /> **(Lưu)** trong thẻ biến. |

Muốn xóa biến, chọn <img src="https://api.iconify.design/lucide:trash-2.svg?color=%23ff3333" width="16" alt="" /> **(Xóa)** trong thẻ biến và xác nhận.

## Sửa hoặc sử dụng Prompt

| Thao tác | Cách thực hiện |
| --- | --- |
| Sửa Prompt | Tại Prompt cần cập nhật, chọn <img src="https://api.iconify.design/lucide:ellipsis-vertical.svg?color=%23ff3333" width="16" alt="" /> **(Menu)** trong cột **Thao tác** → **Sửa** → cập nhật nội dung → chọn <img src="https://api.iconify.design/lucide:check.svg?color=%23ff3333" width="16" alt="" /> **(Lưu)**. |
| Sử dụng Prompt | Chọn <img src="https://api.iconify.design/lucide:ellipsis-vertical.svg?color=%23ff3333" width="16" alt="" /> **(Menu)** → **Sử dụng**. Nếu Prompt có biến, nhập giá trị trong panel bên phải rồi chọn <img src="https://api.iconify.design/lucide:check.svg?color=%23ff3333" width="16" alt="" /> **(Xác nhận)**. Nội dung Prompt được đưa vào ô nhập của Chat Panel. |

## Gọi Prompt bằng phím tắt /

| Bước | Cách thực hiện |
| --- | --- |
| 1 | Chọn ô nhập nội dung trong Chat Panel và gõ `/`. |
| 2 | Chọn Prompt từ danh sách hoặc nhập tiếp phím tắt của Prompt. |
| 3 | Nhập giá trị biến nếu Prompt yêu cầu. |
| 4 | Chọn <img src="https://api.iconify.design/lucide:send.svg?color=%23ff3333" width="16" alt="" /> **(Gửi)**. |

> [!NOTE]
> Khi chuyển Base, Thư viện Prompt chỉ hiển thị Prompt và danh mục của Base mới.

## Mở khu vực tạo tích hợp mới

| Bước | Cách thực hiện |
| --- | --- |
| 1 | Mở **Tools & MCP (Công cụ)** trên RedAI. |
| 2 | Chọn **Tích hợp Tools (External)** để mở danh sách các tích hợp hiện có. |
| 3 | Chọn <img src="https://api.iconify.design/lucide:plus.svg?color=%23ff3333" width="16" alt="" /> **(Thêm mới)**. Khung **Tạo tích hợp mới** mở ở bên phải. |

## Các bước thực hiện

### Chọn phương án thực hiện

| Phương án | Dùng khi | Điều kiện |

| <img src="https://api.iconify.design/lucide:upload.svg?color=%23ff3333" width="16" alt="" /> **Upload File** | Muốn tải đặc tả OpenAPI từ một tệp có sẵn. | Có tệp OpenAPI để tải lên. |

### Tạo tích hợp bằng Upload File

| Bước | Cách thực hiện |
| --- | --- |
| 1 | Chọn <img src="https://api.iconify.design/lucide:upload.svg?color=%23ff3333" width="16" alt="" /> **Upload File**. |
| 2 | Chọn khu vực **Chọn file OpenAPI JSON**, sau đó nhấp để tải tệp lên, kéo và thả tệp vào vùng tải lên hoặc dùng thao tác dán từ clipboard được giao diện hỗ trợ. |
| 3 | Chờ RedAI phân tích tệp. Tiếp tục khi giao diện hiển thị **OpenAPI specification hợp lệ!**. |
| 4 | Chọn <img src="https://api.iconify.design/lucide:check.svg?color=%23ff3333" width="16" alt="" /> **(Xác nhận)** để tạo tích hợp hoặc chọn <img src="https://api.iconify.design/lucide:x.svg?color=%23ff3333" width="16" alt="" /> **(Hủy)** để đóng khung. |

### Tạo tích hợp bằng Paste JSON Code

| Bước | Cách thực hiện |
| --- | --- |
| 1 | Chọn <img src="https://api.iconify.design/lucide:code-2.svg?color=%23ff3333" width="16" alt="" /> **Paste JSON Code**. |
| 2 | Dán toàn bộ nội dung OpenAPI JSON vào trường **Đặc tả OpenAPI**. |
| 3 | Chờ RedAI phân tích nội dung. Tiếp tục khi giao diện hiển thị **OpenAPI specification hợp lệ!**. |
| 4 | Chọn <img src="https://api.iconify.design/lucide:check.svg?color=%23ff3333" width="16" alt="" /> **(Xác nhận)** để tạo tích hợp hoặc chọn <img src="https://api.iconify.design/lucide:x.svg?color=%23ff3333" width="16" alt="" /> **(Hủy)** để đóng khung. |

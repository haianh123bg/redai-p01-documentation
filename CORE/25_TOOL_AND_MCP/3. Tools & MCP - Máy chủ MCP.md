## Mở khu vực quản lý máy chủ MCP

| Bước | Cách thực hiện |
| --- | --- |
| 1 | Mở **Tools & MCP (Công cụ)** trong RedAI. |
| 2 | Chọn **Máy chủ MCP**. Danh sách hiển thị **Tên Server**, **Số lượng công cụ**, **URL** và **Ngày tạo**. |

## Các tính năng

### Thêm máy chủ MCP

| Bước | Cách thực hiện |
| --- | --- |
| 1 | Chọn <img src="https://api.iconify.design/lucide:plus.svg?color=%23ff3333" width="16" alt="" /> **Thêm mới** để mở khung **Tạo MCP Server mới**. |
| 2 | Nhập **Tên Server** và **Mô tả**. |
| 3 | Nhập **URL** của MCP Server, ví dụ `https://example.com/mcp`. |
| 4 | Nếu cần gửi Header, nhập **Header key** và **Header value**. Chọn <img src="https://api.iconify.design/lucide:plus.svg?color=%23ff3333" width="16" alt="" /> để thêm một dòng Header khác. |
| 5 | Chọn <img src="https://api.iconify.design/lucide:check.svg?color=%23ff3333" width="16" alt="" /> **Xác nhận** để lưu. Chọn <img src="https://api.iconify.design/lucide:x.svg?color=%23ff3333" width="16" alt="" /> **Hủy** để đóng mà không lưu. |

> **Lưu ý:** Chỉ những Header có đầy đủ key và value mới được gửi đi. Khi dùng Bearer Token, có thể nhập key `Authorization` và value `Bearer <token>`.

### Tìm kiếm và làm mới danh sách

| Tính năng | Cách thực hiện |
| --- | --- |
| Tìm kiếm | Chọn <img src="https://api.iconify.design/lucide:search.svg?color=%23ff3333" width="16" alt="" /> **Tìm kiếm**, sau đó nhập tên máy chủ MCP cần tìm. |
| Làm mới | Chọn <img src="https://api.iconify.design/lucide:refresh-cw.svg?color=%23ff3333" width="16" alt="" /> **Làm mới** để tải lại danh sách và số lượng công cụ hiện tại. |

## Gắn Project tại Tài nguyên

1. Mở Agent cần cấu hình.
2. Chọn biểu tượng <img src="https://api.iconify.design/lucide:pencil.svg?color=%23ff3333" width="16" alt="" /> **(Chỉnh sửa)** tại dòng **Tài nguyên**.
3. Trong màn hình **Chọn Projects**, tìm Project tại khu vực **Thư viện Projects**.
4. Đánh dấu một hoặc nhiều Project cần gắn.
5. Chọn biểu tượng <img src="https://api.iconify.design/lucide:check.svg?color=%23ff3333" width="16" alt="" /> **(Lưu)**.

Khu vực **Projects của agent** hiển thị các Project đã được gắn. Agent có thể truy xuất các loại dữ liệu nằm trong Project, chẳng hạn Knowledge files, Media, URLs, Products và Tables.

> **Lưu ý:** Agent không thể chọn Project thuộc Base khác.

## Gắn Skill

1. Chọn biểu tượng <img src="https://api.iconify.design/lucide:pencil.svg?color=%23ff3333" width="16" alt="" /> **(Chỉnh sửa)** tại dòng **Skills**.
2. Tìm Skill trong **Thư viện Skills** bằng biểu tượng <img src="https://api.iconify.design/lucide:search.svg?color=%23ff3333" width="16" alt="" /> **(Tìm kiếm)**.
3. Chọn biểu tượng <img src="https://api.iconify.design/lucide:funnel.svg?color=%23ff3333" width="16" alt="" /> **(Bộ lọc)** để chọn **Tất cả**, **Skill cá nhân** hoặc **Skill hệ thống**.
4. Chọn Skill cần gắn cho Agent.
5. Lưu cấu hình.

Skill là lớp năng lực được gắn vào Agent, giúp Agent chuyển từ vai trò trợ lý hội thoại sang nhân sự số có khả năng thực thi nghiệp vụ thực tế. Skill chỉ dẫn Agent sử dụng Docs, Tools, MCPs và Workflows theo đúng mục tiêu và quy trình. Agent chỉ có thể thực hiện tác vụ của một module khi đã được gắn Skill cung cấp năng lực tương ứng.

## Cấu hình Memory Agent

Khu vực **Bộ nhớ** trên giao diện dùng để cấu hình **Memory Agent**, tức cơ chế Long-term Memory được tổ chức dưới dạng Graph RAG. Đây là một phần của kiến trúc Memory đa tầng, không đại diện cho toàn bộ Long-term Memory, Short-term Memory và Working Memory.

1. Chọn biểu tượng <img src="https://api.iconify.design/lucide:pencil.svg?color=%23ff3333" width="16" alt="" /> **(Chỉnh sửa)** tại dòng **Bộ nhớ**.
2. Bật **Bật bảo trì nền** nếu muốn hệ thống tự động trích xuất và cấu trúc hóa Long-term Memory bằng Agent nền.
3. Nhập số lượt tại **Chạy mỗi N lượt**.
4. Lưu cấu hình.

Agent nền mặc định được nhân bản từ Agent chính và chạy sau số lượt đã đặt. Dữ liệu được tổ chức theo luồng `Trích xuất → Graph → RAG → Graph RAG` mà không làm gián đoạn hội thoại hiện tại.

Trong **Bộ nhớ Graph**, có thể dùng ô `Tìm nhanh: node:, edge:` để tra cứu node hoặc edge của Agent.

## Định nghĩa chuyển đổi

**Định nghĩa chuyển đổi** cho phép ghim một mục tiêu (goal) cụ thể cho Agent. Khi được cấu hình, Agent bám sát mục tiêu này trong toàn bộ quá trình tương tác với khách hàng và chủ động điều chỉnh cách đặt câu hỏi, cách phản hồi cũng như cách thu thập thông tin để hướng đến kết quả đã đặt ra.

1. Chọn biểu tượng <img src="https://api.iconify.design/lucide:pencil.svg?color=%23ff3333" width="16" alt="" /> **(Chỉnh sửa)** tại dòng **Định nghĩa chuyển đổi**.
2. Chọn biểu tượng <img src="https://api.iconify.design/lucide:plus.svg?color=%23ff3333" width="16" alt="" /> **(Thêm trường mới)**.
3. Chọn các trường Agent cần thu thập, chẳng hạn tên, email, số điện thoại hoặc trường dữ liệu phù hợp khác.
4. Bật **required** đối với trường bắt buộc.
5. Chọn biểu tượng <img src="https://api.iconify.design/lucide:trash-2.svg?color=%23ff3333" width="16" alt="" /> **(Xóa)** trên trường không còn sử dụng.
6. Chọn biểu tượng <img src="https://api.iconify.design/lucide:check.svg?color=%23ff3333" width="16" alt="" /> **(Lưu)**.

Các trường dữ liệu được chọn là thông tin Agent cần thu thập để phục vụ mục tiêu chuyển đổi; chúng không phải toàn bộ ý nghĩa của Định nghĩa chuyển đổi.

## Cấu hình Chiến lược trước và sau thực thi

1. Chọn biểu tượng <img src="https://api.iconify.design/lucide:pencil.svg?color=%23ff3333" width="16" alt="" /> **(Chỉnh sửa)** tại dòng **Chiến lược**.
2. Tại **Pre-Execution Strategy Agent**, chọn Agent cần chạy trước Agent chính.
3. Tại **Post-Execution Strategy Agent**, chọn Agent cần chạy sau Agent chính.
4. Thiết lập trường **Hoạt động sau n lần chạy** nếu quy trình của Agent cần sử dụng.
5. Lưu cấu hình.

Pre-Execution Agent xử lý trước Agent chính; Post-Execution Agent xử lý sau Agent chính.

## Cấu hình SubAgent

1. Chọn biểu tượng <img src="https://api.iconify.design/lucide:pencil.svg?color=%23ff3333" width="16" alt="" /> **(Chỉnh sửa)** tại dòng **Subagent**.
2. Nhập giới hạn tại **Số nhiệm vụ agent con tối đa mỗi thread**.
3. Tại **Chọn Agent khác để thêm làm Subagent**, chọn một Agent có chuyên môn cần phối hợp.
4. Nhập **Mô tả subagent** để xác định chuyên môn, tình huống hoặc loại việc cần giao.
5. Chọn <img src="https://api.iconify.design/lucide:plus.svg?color=%23ff3333" width="16" alt="" /> **(Thêm Subagent)**.
6. Lặp lại các bước trên để bổ sung các Agent có chuyên môn khác khi cần.
7. Quản lý các Agent đã thêm tại **Danh sách Subagent**.
8. Lưu cấu hình.

RedAI hỗ trợ tối đa 8 SubAgent chạy song song theo cơ chế Swarm. Agent chính có thể phối hợp với nhiều Agent có chuyên môn, Skill và Tool riêng; không bị giới hạn ở một Agent duy nhất. Tác vụ `agent_subtask` đã hoàn thành hoặc thất bại không tiếp tục chiếm slot trong thread.

## Thiết kế Chiến lược Flow

1. Chọn biểu tượng <img src="https://api.iconify.design/lucide:pencil.svg?color=%23ff3333" width="16" alt="" /> **(Chỉnh sửa)** tại dòng **Chiến lược Flow**.
2. Chọn <img src="https://api.iconify.design/lucide:plus.svg?color=%23ff3333" width="16" alt="" /> trên node bắt đầu để thêm bước xử lý.
3. Điền các trường:

| Trường | Nội dung |
| --- | --- |
| **Tên bước** | Tên nhận biết của bước xử lý. |
| **Mô tả công việc** | Công việc Agent cần thực hiện tại bước này. |
| **Ví dụ Input/Output** | Ví dụ dữ liệu đầu vào và kết quả đầu ra. |
| **Điều kiện kích hoạt** | Điều kiện để bước được thực thi. |

4. Chọn <img src="https://api.iconify.design/lucide:check.svg?color=%23ff3333" width="16" alt="" /> **(Lưu bước)** hoặc <img src="https://api.iconify.design/lucide:x.svg?color=%23ff3333" width="16" alt="" /> **(Hủy)**.
5. Lặp lại để tạo các bước tiếp theo.

Các thao tác bổ sung:

| Biểu tượng | Chức năng |
| --- | --- |
| <img src="https://api.iconify.design/lucide:wand-sparkles.svg?color=%23ff3333" width="16" alt="" /> **(Tạo Flow bằng AI)** | Nhập yêu cầu để AI hỗ trợ tạo nội dung hoặc cấu trúc Flow. |
| <img src="https://api.iconify.design/lucide:upload.svg?color=%23ff3333" width="16" alt="" /> **(Nhập Flow Schema)** | Chọn tệp Schema từ thiết bị để nhập vào Flow. |
| <img src="https://api.iconify.design/lucide:download.svg?color=%23ff3333" width="16" alt="" /> **(Xuất Flow Schema)** | Xuất Schema của Flow xuống thiết bị. |

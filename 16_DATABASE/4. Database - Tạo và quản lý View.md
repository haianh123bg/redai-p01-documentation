## Mở khu vực quản lý View

| Bước | Cách thực hiện |
| --- | --- |
| 1 | Mở **Database** trên RedAI, sau đó chọn **Tất cả bảng** trong khu vực **Danh mục**. |
| 2 | Chọn danh mục nếu cần, sau đó tìm bảng chứa View muốn quản lý. |
| 3 | Chọn dòng của bảng hoặc mũi tên ở cuối dòng để hiển thị các View bên dưới. |
| 4 | Chọn View cần mở hoặc quản lý. |

## Các tính năng

### Mở và thêm View

| Tính năng | Cách thực hiện |
| --- | --- |
| **Hiển thị View** | Chọn dòng của bảng hoặc mũi tên ở cuối dòng. Các View hiện có xuất hiện bên dưới tên bảng. |
| <img src="https://api.iconify.design/lucide:table-2.svg?color=%23ff3333" width="16" alt="" /> **Mở View** | Chọn tên View, chẳng hạn **Tất cả dữ liệu** hoặc **Export**, để mở dữ liệu theo cấu hình của View đó. |
| <img src="https://api.iconify.design/lucide:plus.svg?color=%23ff3333" width="16" alt="" /> **Thêm View** | Chọn **Thêm view...** bên dưới bảng và hoàn tất cấu hình đang hiển thị. |

### Tạo các loại View

| Loại View | Giải thích |
| --- | --- |
| <img src="https://api.iconify.design/lucide:table-2.svg?color=%23ff3333" width="16" alt="" /> **Grid** | Hiển thị dữ liệu dạng bảng gồm hàng và cột, cho phép quan sát nhiều trường trên cùng một màn hình. |
| <img src="https://api.iconify.design/lucide:clipboard-pen.svg?color=%23ff3333" width="16" alt="" /> **Form** | Hiển thị các trường dưới dạng biểu mẫu để người dùng nhập dữ liệu cho từng bản ghi. |
| <img src="https://api.iconify.design/lucide:images.svg?color=%23ff3333" width="16" alt="" /> **Gallery** | Hiển thị mỗi bản ghi dưới dạng thẻ và có thể sử dụng trường tệp đính kèm làm ảnh bìa. |
| <img src="https://api.iconify.design/lucide:columns-3.svg?color=%23ff3333" width="16" alt="" /> **Kanban** | Chia bản ghi thành các cột dựa trên trạng thái hoặc trường phân nhóm. |
| <img src="https://api.iconify.design/lucide:calendar-days.svg?color=%23ff3333" width="16" alt="" /> **Calendar** | Đưa bản ghi lên lịch dựa vào trường ngày bắt đầu và trường ngày kết thúc nếu có. |

| Hạng mục cấu hình | Áp dụng cho | Cách cấu hình |
| --- | --- | --- |
| Bắt đầu tạo | Tất cả View | Hiển thị danh sách View, sau đó chọn <img src="https://api.iconify.design/lucide:plus.svg?color=%23ff3333" width="16" alt="" /> **Thêm view...**. |
| Loại View | Tất cả View | Chọn **Grid**, **Form**, **Gallery**, **Kanban** hoặc **Calendar**. Trong bước cấu hình, chọn **Thay đổi** nếu cần chọn lại loại View. |
| Tên View | Tất cả View | Nhập tên giúp nhận biết mục đích sử dụng, chẳng hạn `Tất cả khách hàng` hoặc `Lịch nội dung`. |
| Mô tả | Tất cả View | Bật **Thêm mô tả**, sau đó nhập mô tả nếu cần giải thích phạm vi hoặc cách sử dụng View. |
| Cấu hình Gallery | <img src="https://api.iconify.design/lucide:images.svg?color=%23ff3333" width="16" alt="" /> **Gallery** | Chọn trường tệp đính kèm làm ảnh bìa khi bảng có trường phù hợp. Nếu chưa có, View được tạo với trạng thái **Không có ảnh bìa**; có thể thêm trường `FILE ATTACHMENT` và chọn ảnh bìa sau. |
| Cấu hình Kanban | <img src="https://api.iconify.design/lucide:columns-3.svg?color=%23ff3333" width="16" alt="" /> **Kanban** | Hoàn tất trường phân nhóm để bản ghi được chia thành các cột. |
| Cấu hình Calendar | <img src="https://api.iconify.design/lucide:calendar-days.svg?color=%23ff3333" width="16" alt="" /> **Calendar** | Chọn **Trường ngày bắt đầu** bắt buộc. Tại **Trường ngày kết thúc (Tùy chọn)**, chọn một trường ngày phù hợp hoặc chọn **Không**. Danh sách lựa chọn phụ thuộc vào cấu trúc bảng. |
| Hoàn tất | Tất cả View | Chọn <img src="https://api.iconify.design/lucide:check.svg?color=%23ff3333" width="16" alt="" /> **Xác nhận** để tạo View hoặc <img src="https://api.iconify.design/lucide:arrow-left.svg?color=%23ff3333" width="16" alt="" /> **Quay lại** nếu chưa muốn hoàn tất. |

### Mở menu quản lý View

| Bước | Cách thực hiện |
| --- | --- |
| 1 | Hiển thị danh sách View của bảng. |
| 2 | Tại View cần quản lý, chọn <img src="https://api.iconify.design/lucide:ellipsis-vertical.svg?color=%23ff3333" width="16" alt="" /> **More** ở bên phải dòng View. |
| 3 | Chọn thao tác phù hợp trong menu đang hiển thị. |

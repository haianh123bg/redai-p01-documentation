## Mở khu vực tích hợp

| Bước | Cách thực hiện |
| --- | --- |
| 1 | Mở **AI Studio** trong RedAI. |
| 2 | Chọn **(Tích hợp)**. Danh sách nhà cung cấp hoặc thông tin xác thực hiện có xuất hiện. |
| 3 | Chọn <img src="https://api.iconify.design/lucide:plus.svg?color=%23ff3333" width="16" alt="" /> **(Thêm kết nối mới)**, sau đó chọn nhà cung cấp model ảnh hoặc video cần sử dụng. |

## Các bước thực hiện

### Kết nối nhà cung cấp

Thực hiện một trong hai cách dưới đây theo phương thức đã chọn.

#### Kết nối qua OAuth

| Bước | Cách thực hiện |
| --- | --- |
| 1 | Trong **(Tích hợp)**, chọn Chat GPT (OAuth), Grok (xAI OAuth),... Khung **Kết nối** mở ở bên phải. |
| 2 | Chọn **(Mở đăng nhập)**. RedAI mở cửa sổ đăng nhập. |
| 3 | Đăng nhập bằng tài khoản ChatGPT cần kết nối và hoàn tất các bước xác thực hoặc cấp quyền đang hiển thị. |
| 4 | Sau khi đăng nhập, trình duyệt chuyển đến địa chỉ bắt đầu bằng `http://localhost:1455/auth/callback`. Sao chép **toàn bộ URL trên thanh địa chỉ**, bao gồm cả tham số `code` và `state`. |
| 5 | Quay lại khung **Kết nối** trong RedAI, dán nguyên URL vừa sao chép vào trường **Callback URL**. |
| 6 | Chọn <img src="https://api.iconify.design/lucide:check.svg?color=%23ff3333" width="16" alt="" /> **(Hoàn tất kết nối)** để RedAI đồng bộ và trao đổi token. |
| 7 | Quay lại danh sách tích hợp và kiểm tra tích hợp. Trạng thái **Đã cấu hình** cho biết kết nối đã hoàn tất. |

#### Kết nối bằng API key

| Bước | Cách thực hiện |
| --- | --- |
| 1 | Đăng nhập trang quản trị của nhà cung cấp (Bikip, Cline, Kling AI,...) bằng tài khoản có quyền tạo API key. |
| 2 | Tạo API key mới. Nếu được hỗ trợ, đặt tên và giới hạn phạm vi khóa theo mục đích sử dụng trong RedAI. |
| 3 | Sao chép API key và lưu tạm ở nơi an toàn. |
| 4 | Quay lại AI Studio, chọn nhà cung cấp và phương thức **(API key)**. |
| 5 | Dán khóa vào trường API key hoặc trường khóa truy cập đang hiển thị. |
| 6 | Nếu có trường tên kết nối, nhập tên dễ nhận biết nhưng không chứa API key. |
| 7 | Chọn <img src="https://api.iconify.design/lucide:check.svg?color=%23ff3333" width="16" alt="" /> **(Lưu)**, **Kết nối** hoặc nút xác nhận tương ứng, sau đó kiểm tra trạng thái kết nối. |

> **Cảnh báo:** Một số nhà cung cấp chỉ hiển thị toàn bộ API key một lần. Nếu nghi ngờ khóa bị lộ, hãy thu hồi khóa tại nhà cung cấp và tạo khóa mới.

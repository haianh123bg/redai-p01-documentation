## Mở khu vực Xuất bản MCP

| Bước | Cách thực hiện |
| --- | --- |
| 1 | Mở **Tools & MCP (Công cụ)** trong RedAI. |
| 2 | Chọn **Xuất bản MCP**. Danh sách hiển thị tên MCP, Skill nguồn, Server key, trạng thái, ngày cập nhật và cột **Thao tác**. |

## Các bước thực hiện

### Chọn Skill nguồn, thiết lập xuất bản và tạo MCP Server

| Bước | Cách thực hiện |
| --- | --- |
| 1 | Chọn <img src="https://api.iconify.design/lucide:plus.svg?color=%23ff3333" width="16" alt="" /> **(Thêm mới)** để mở khung **Tạo và xuất bản MCP**. |
| 2 | Tại **Skill nguồn**, chọn **Tìm và chọn skill**. Trong cửa sổ **Chọn skill nguồn**, chọn **Cá nhân** hoặc **Hệ thống**, tìm kiếm nếu cần rồi chọn Skill muốn xuất bản. |
| 3 | Nhập **Tên MCP server** và **Mô tả**. Nếu để trống tên, hệ thống mặc định lấy theo tên Skill. |
| 4 | Nếu muốn giới hạn thời gian sử dụng API key đầu tiên, chọn ngày và giờ tại **Hạn API key đầu tiên**. Có thể để trống nếu không đặt ngày hết hạn. |
| 5 | Bật **Xuất bản ngay sau khi tạo** nếu muốn MCP Server chuyển sang trạng thái đã xuất bản ngay khi lưu. |
| 6 | Bật **Tạo sẵn API key đầu tiên** nếu muốn hệ thống tạo khóa truy cập cùng MCP Server. |
| 7 | Chọn <img src="https://api.iconify.design/lucide:check.svg?color=%23ff3333" width="16" alt="" /> **(Xác nhận)** để tạo MCP Server. |

> **Lưu ý:** Chọn đúng Skill nguồn vì nội dung và năng lực được cung cấp qua MCP Server sẽ dựa trên Skill này.

> **Cảnh báo:** API key là thông tin xác thực. Không đưa API key vào tài liệu công khai, ảnh chụp màn hình, mã nguồn hoặc nội dung trao đổi không được bảo vệ.

## Các tính năng quản lý MCP

### Mở các chức năng quản lý

| Tính năng | Cách thực hiện |
| --- | --- |
| <img src="https://api.iconify.design/lucide:ellipsis-vertical.svg?color=%23ff3333" width="16" alt="" /> **(Mở menu thao tác)** | Tại MCP Server cần quản lý, chọn nút ba chấm trong cột **Thao tác**. Menu thay đổi theo trạng thái: MCP đã xuất bản có **Lưu trữ**; MCP đang **Lưu trữ** có **Xuất bản** và **Xóa**. |
| <img src="https://api.iconify.design/lucide:eye.svg?color=%23ff3333" width="16" alt="" /> **Xem chi tiết** | Mở màn hình gồm các tab **Thông tin chung**, **Cấu hình sử dụng** và **Lịch sử**. |
| <img src="https://api.iconify.design/lucide:list.svg?color=%23ff3333" width="16" alt="" /> **Xem danh sách API Key** | Xem các khóa, trạng thái và thời hạn đang áp dụng. |
| <img src="https://api.iconify.design/lucide:key-round.svg?color=%23ff3333" width="16" alt="" /> **Tạo API key** | Nhập **Tên API key**, chọn **Hạn API key** nếu cần rồi xác nhận tạo khóa. |
| <img src="https://api.iconify.design/lucide:archive.svg?color=%23ff3333" width="16" alt="" /> **Lưu trữ** | Lưu trữ MCP Server khi không muốn tiếp tục sử dụng máy chủ trong danh sách hoạt động. |
| <img src="https://api.iconify.design/lucide:upload.svg?color=%23ff3333" width="16" alt="" /> **Xuất bản** | Chỉ hiển thị khi MCP Server đang ở trạng thái **Lưu trữ**. Chọn để đưa MCP Server trở lại trạng thái **Đã publish**. |

> **Lưu ý:** Khi MCP Server đang ở trạng thái **Lưu trữ**, mở menu **Thao tác** và chọn <img src="https://api.iconify.design/lucide:upload.svg?color=%23ff3333" width="16" alt="" /> **Xuất bản** để kích hoạt lại. Kiểm tra cấu hình sử dụng và API key trước khi cho MCP client kết nối lại.

> **Cảnh báo:** Trước khi lưu trữ MCP Server hoặc xóa một API key, kiểm tra các MCP client và quy trình đang sử dụng Server key hoặc khóa đó để tránh làm gián đoạn kết nối.

### Xem thông tin chung và quản lý API key

Trong **Xem chi tiết**, chọn tab **Thông tin chung**.

| Tính năng | Cách thực hiện |
| --- | --- |
| **Xem thông tin MCP** | Kiểm tra tên MCP, Skill nguồn, trạng thái, Server key và số lượng **Tools**, **Workflows**, **Docs**. |
| <img src="https://api.iconify.design/lucide:key-round.svg?color=%23ff3333" width="16" alt="" /> **(Tạo thêm API key)** | Trong phần **API keys**, nhập tên và thời hạn rồi xác nhận tạo. |
| <img src="https://api.iconify.design/lucide:copy.svg?color=%23ff3333" width="16" alt="" /> **(Sao chép API key)** | Tại API key cần dùng, chọn nút sao chép. |
| <img src="https://api.iconify.design/lucide:trash-2.svg?color=%23ff3333" width="16" alt="" /> **(Xóa API key)** | Tại API key không còn sử dụng, chọn nút xóa và xác nhận. |

> **Cảnh báo:** Sau khi xóa, các cấu hình đang dùng API key đó sẽ không thể xác thực với MCP Server. Hãy thay khóa trên MCP client trước khi thu hồi khóa cũ.

### Sao chép cấu hình sử dụng MCP

Trong **Xem chi tiết**, chọn tab **Cấu hình sử dụng**. Hệ thống cung cấp các mẫu cấu hình cho **Codex CLI**, **Claude Code/Desktop MCP JSON**, **Generic MCP remote server** và **NPX bridge MCP JSON**.

| Bước | Cách thực hiện |
| --- | --- |
| 1 | Chọn mẫu tương ứng với MCP client đang sử dụng. |
| 2 | Chọn <img src="https://api.iconify.design/lucide:copy.svg?color=%23ff3333" width="16" alt="" /> **(Sao chép)** tại khối cấu hình. |
| 3 | Dán cấu hình vào MCP client và thay placeholder API key bằng API key thật nếu mẫu chưa tự điền khóa. |

> **Lưu ý:** Nếu API key vừa được tạo trong phiên hiện tại, hệ thống có thể tự thay placeholder bằng khóa thật khi sao chép. Luôn kiểm tra cấu hình trước khi lưu vào client.

### Xem lịch sử sử dụng

Trong **Xem chi tiết**, chọn tab **Lịch sử**. Bảng lịch sử hiển thị hành động, mã trạng thái, độ trễ, mã lỗi, API key và thời gian cập nhật. Có thể dùng <img src="https://api.iconify.design/lucide:search.svg?color=%23ff3333" width="16" alt="" /> **(Tìm kiếm)**, <img src="https://api.iconify.design/lucide:list-filter.svg?color=%23ff3333" width="16" alt="" /> **(Bộ lọc)** hoặc <img src="https://api.iconify.design/lucide:refresh-cw.svg?color=%23ff3333" width="16" alt="" /> **(Làm mới)** để tra cứu lần gọi cần kiểm tra.

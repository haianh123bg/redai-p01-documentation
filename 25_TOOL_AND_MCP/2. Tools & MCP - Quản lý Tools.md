## Mở khu vực quản lý

| Bước | Cách thực hiện |
| --- | --- |
| 1 | Mở **Tools & MCP (Công cụ)** trên RedAI. |
| 2 | Chọn **Tích hợp Tools (External)** để mở danh sách các tích hợp hiện có. |

## Các tính năng

### Tìm, lọc và nhận biết tích hợp

| Khu vực hoặc chức năng | Cách sử dụng |
| --- | --- |
| **Cá nhân** và **Hệ thống** | Chuyển giữa danh sách tích hợp thuộc phạm vi cá nhân và danh sách tích hợp hệ thống. |
| **Bộ lọc Type** | Chọn **Tất cả** hoặc một Type đang hiển thị: **Nền tảng**, **Tài khoản ngân hàng**, **LLM**, **SMS**, **Email**, **Google Workspace**, **Mạng xã hội**, **Vận chuyển**, **Website**, **Thương mại điện tử**, **Marketing**, **Bán hàng**, **Thiết kế**, **Năng suất**, **Lập trình viên**, **Du lịch**, **Database**, **Tích hợp tùy chỉnh**, **Proxy**, **Computer Use** hoặc **GCP**. |
| <img src="https://api.iconify.design/lucide:search.svg?color=%23ff3333" width="16" alt="" /> **(Tìm kiếm)** | Chọn nút tìm kiếm, sau đó nhập tên tích hợp vào trường **Tìm kiếm công cụ...**. |
| <img src="https://api.iconify.design/lucide:refresh-cw.svg?color=%23ff3333" width="16" alt="" /> **(Tải lại dữ liệu)** | Tải lại danh sách tích hợp đang hiển thị. |

### Mở chi tiết tích hợp

| Bước | Cách thực hiện |
| --- | --- |
| 1 | Chọn **bộ công cụ tích hợp** cần quản lý. |
| 2 | Tại trang **Chi tiết ứng dụng**, kiểm tra tên, phạm vi, tổng số tool, ngày tạo và ngày cập nhật. |
| 3 | Mở tab **Danh sách tools** để xem các tool thuộc tích hợp. |

Danh sách có thể hiển thị các thông tin như **Tên**, **Mô tả**, **URL**, **Phương thức**, **Loại xác thực**, **Ngày tạo**, **Ngày cập nhật**, **Trạng thái** và **Thao tác**.

Khi cột **URL** hiển thị, chọn <img src="https://api.iconify.design/lucide:copy.svg?color=%23ff3333" width="16" alt="" /> trong hàng tương ứng để sao chép URL của tool.

### Sử dụng thanh công cụ trong chi tiết ứng dụng

| Tính năng | Cách thực hiện | Kết quả hoặc lưu ý |
| --- | --- | --- |
| <img src="https://api.iconify.design/lucide:plus.svg?color=%23ff3333" width="16" alt="" /> **Tạo tích hợp mới** | Chọn nút **Tạo tích hợp mới**. Trong tab **Tạo mới**, chọn một trong ba cách: **Upload File** để tải tệp OpenAPI JSON lên; **Paste JSON Code** để dán trực tiếp đặc tả OpenAPI; hoặc **Tạo bằng form** để nhập **Tên tool**, **HTTP Method**, **Endpoint path**, **Mô tả**, **Input schema**, **Output schema**, **Input example** và **Output example**. Nếu muốn lấy cấu hình từ project, chuyển sang tab **Tạo từ project**. | Kiểm tra dữ liệu đã nhập hoặc tệp đã tải lên, sau đó chọn <img src="https://api.iconify.design/lucide:check.svg?color=%23ff3333" width="16" alt="" /> **(Xác nhận)** để tạo. |
| <img src="https://api.iconify.design/lucide:search.svg?color=%23ff3333" width="16" alt="" /> **Tìm kiếm** | Chọn nút tìm kiếm và nhập giá trị vào trường vừa mở. | Lọc danh sách tool theo nội dung tìm kiếm. |
| <img src="https://api.iconify.design/lucide:download.svg?color=%23ff3333" width="16" alt="" /> **Export OpenAPI JSON** | Chọn nút tải xuống. | Xuất đặc tả OpenAPI JSON của bộ công cụ tích hợp hiện tại. |
| <img src="https://api.iconify.design/lucide:settings.svg?color=%23ff3333" width="16" alt="" /> **Cài đặt project** | Mở màn hình **Cài đặt project**. Chọn <img src="https://api.iconify.design/lucide:square-pen.svg?color=%23ff3333" width="16" alt="" /> tại tên, **Mô tả**, **Phân loại (Tab)**, **Base URLs** hoặc **Cấu hình xác thực** cần cập nhật; nhập nội dung rồi xác nhận để lưu. | Dùng để cập nhật cấu hình chung của bộ công cụ tích hợp. Nếu chọn **Xóa project schema**, toàn bộ tools và versions của bộ công cụ tích hợp sẽ bị xóa vĩnh viễn. |
| <img src="https://api.iconify.design/lucide:refresh-cw.svg?color=%23ff3333" width="16" alt="" /> **Tải lại dữ liệu** | Chọn nút tải lại. | Tải lại danh sách tool và trạng thái mới nhất. |
| **Danh sách tools** | Chọn tab **Danh sách tools**. | Xem tên, mô tả, URL, phương thức, loại xác thực, ngày tạo, ngày cập nhật, trạng thái và thao tác của từng tool. Khi cột **URL** hiển thị, chọn <img src="https://api.iconify.design/lucide:copy.svg?color=%23ff3333" width="16" alt="" /> để sao chép URL. |
| **Lịch sử sử dụng tool** | Chọn tab **Lịch sử sử dụng tool**. | Xem **Agent**, **Tên tool**, **Loại**, **Số lần**, **Thời gian** và **Người dùng**. Trạng thái **Thành công** hoặc **Lỗi** cho biết kết quả của lượt chạy. |

### Thao tác với từng tool

Tại hàng của tool cần quản lý, chọn <img src="https://api.iconify.design/lucide:ellipsis-vertical.svg?color=%23ff3333" width="16" alt="" /> trong cột **Thao tác**, sau đó chọn chức năng cần dùng.

| Thao tác | Cách thực hiện | Kết quả hoặc lưu ý |
| --- | --- | --- |
| <img src="https://api.iconify.design/lucide:eye.svg?color=%23ff3333" width="16" alt="" /> **Xem contract** | Chọn **Xem contract**, sau đó kiểm tra tên, mô tả, phương thức, phiên bản, trạng thái mặc định, **Endpoint**, **Base URLs**, **Input Schema** và **Output Schema**. | Chọn <img src="https://api.iconify.design/lucide:copy.svg?color=%23ff3333" width="16" alt="" /> **Sao chép** khi cần sao chép schema đang hiển thị. |
| <img src="https://api.iconify.design/lucide:square-pen.svg?color=%23ff3333" width="16" alt="" /> **Sửa** | Chọn **Sửa**. Cập nhật **Tên Tool**, phiên bản, **Endpoint**, **Phương thức**, **Mô tả**, **Base URLs**, **Input Schema**, **Output Schema**, **Input Example** hoặc **Output Example**, sau đó chọn **Lưu**. | Thay đổi cấu hình của đúng tool và phiên bản đang chỉnh sửa. Kiểm tra nhãn **Version mặc định** trước khi lưu. |
| <img src="https://api.iconify.design/lucide:link-2.svg?color=%23ff3333" width="16" alt="" /> **Cập nhật URL gốc** | Chọn **Cập nhật URL gốc**, sửa URL hiện có hoặc chọn <img src="https://api.iconify.design/lucide:plus.svg?color=%23ff3333" width="16" alt="" /> để thêm URL, rồi chọn <img src="https://api.iconify.design/lucide:check.svg?color=%23ff3333" width="16" alt="" /> **(Xác nhận)**. | Có thể thêm nhiều URL để hỗ trợ chuyển đổi dự phòng hoặc cân bằng tải. |
| <img src="https://api.iconify.design/lucide:square-pen.svg?color=%23ff3333" width="16" alt="" /> **Cập nhật xác thực** | Chọn **Cập nhật xác thực**, kiểm tra loại xác thực hiện tại, chọn loại xác thực cần dùng rồi chọn <img src="https://api.iconify.design/lucide:check.svg?color=%23ff3333" width="16" alt="" /> **(Xác nhận)**. | Cập nhật cấu hình xác thực cho đúng tool đã chọn. Chọn <img src="https://api.iconify.design/lucide:x.svg?color=%23ff3333" width="16" alt="" /> **(Hủy)** nếu không muốn lưu thay đổi. |

> **Phân biệt phạm vi:** <img src="https://api.iconify.design/lucide:settings.svg?color=%23ff3333" width="16" alt="" /> **Cài đặt project** cập nhật cấu hình chung của bộ công cụ tích hợp; các lựa chọn trong <img src="https://api.iconify.design/lucide:ellipsis-vertical.svg?color=%23ff3333" width="16" alt="" /> **Thao tác** chỉ áp dụng cho tool đang chọn.

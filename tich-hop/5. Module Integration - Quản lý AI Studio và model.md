## Tạo kết nối AI Studio

| Bước | Thao tác |
| --- | --- |
| 1 | Mở tab **AI Studio**. |
| 2 | Chọn biểu tượng <img src="https://api.iconify.design/lucide:plus.svg?color=%23ff3333" width="16" alt="" /> **(Thêm mới)**. |
| 3 | Chọn nhà cung cấp LLM. |
| 4 | Nhập thông tin xác thực hoặc hoàn tất OAuth theo biểu mẫu. |
| 5 | Chọn biểu tượng <img src="https://api.iconify.design/lucide:check.svg?color=%23ff3333" width="16" alt="" /> **(Lưu/Xác nhận)**. |

Các trường xác thực phụ thuộc vào nhà cung cấp. Ví dụ, kết nối API có thể yêu cầu tên hiển thị và API Key; kết nối Subscription hoặc Google có thể sử dụng quy trình đăng nhập.

## Cấu hình model

Tùy nhà cung cấp, biểu mẫu model có thể hiển thị:

| Nhóm cấu hình | Nội dung |
| --- | --- |
| Model ID | Mã model do nhà cung cấp công bố. |
| Input modalities | Loại đầu vào model hỗ trợ. |
| Max tokens | Giới hạn token đầu ra. |
| Context window | Dung lượng ngữ cảnh model hỗ trợ. |
| Sampling parameters | Các tham số điều khiển cách model sinh kết quả. |
| Features | Các khả năng bổ sung của model. |
| Responses API | Công tắc sử dụng Responses API nếu model và nhà cung cấp hỗ trợ. |

Chỉ khai báo giá trị đúng với thông số thực tế của model. Cấu hình sai giới hạn token, context window hoặc tính năng hỗ trợ có thể làm yêu cầu thất bại.

## Đồng bộ model

Thao tác **Đồng bộ model** chỉ xuất hiện trên các kết nối được hỗ trợ.

| Bước | Thao tác |
| --- | --- |
| 1 | Mở tab **Tích hợp** hoặc vị trí đang hiển thị kết nối LLM. |
| 2 | Chọn biểu tượng <img src="https://api.iconify.design/lucide:ellipsis-vertical.svg?color=%23ff3333" width="16" alt="" /> **(Thao tác)** tại kết nối. |
| 3 | Chọn **Đồng bộ model**. |

**Kiểm tra kết quả:** Mở lại danh sách model hoặc chọn biểu tượng <img src="https://api.iconify.design/lucide:refresh-cw.svg?color=%23ff3333" width="16" alt="" /> **(Tải lại dữ liệu)** để xem dữ liệu mới nhất.

## Quản lý combo model

| Bước | Thao tác |
| --- | --- |
| 1 | Chọn biểu tượng <img src="https://api.iconify.design/lucide:layers.svg?color=%23ff3333" width="16" alt="" /> **(Danh sách combo model)**. |
| 2 | Mở combo model cần xem hoặc quản lý. |
| 3 | Thực hiện các thao tác đang được hiển thị trong khu vực combo. |

Combo model dùng để tổ chức nhiều cấu hình model thành một nhóm phục vụ quá trình lựa chọn và vận hành. Không nhầm combo model với một kết nối nhà cung cấp riêng lẻ.

## Xuất dữ liệu tích hợp

| Bước | Thao tác |
| --- | --- |
| 1 | Chọn biểu tượng <img src="https://api.iconify.design/lucide:upload.svg?color=%23ff3333" width="16" alt="" /> **(Xuất/Nhập dữ liệu tích hợp)**. |
| 2 | Chọn tab **Xuất dữ liệu**. |
| 3 | Chọn dữ liệu cần xuất theo các tùy chọn được hiển thị. |
| 4 | Thực hiện xuất dữ liệu. |

Dữ liệu xuất có thể gồm thông tin nhà cung cấp, model, giá và khả năng của model theo phạm vi lựa chọn trên giao diện.

## Nhập dữ liệu tích hợp

| Bước | Thao tác |
| --- | --- |
| 1 | Chọn biểu tượng <img src="https://api.iconify.design/lucide:upload.svg?color=%23ff3333" width="16" alt="" /> **(Xuất/Nhập dữ liệu tích hợp)**. |
| 2 | Chọn tab **Nhập dữ liệu**. |
| 3 | Chọn tệp định dạng **.JSON** trên thiết bị. |
| 4 | Thực hiện nhập dữ liệu theo nút xác nhận trong panel. |

> **Lưu ý:** Giao diện hiện hỗ trợ tệp **.JSON** có dung lượng tối đa **2 MB**.

## Xóa kết nối AI Studio

Trên giao diện hiện tại, menu của dòng AI Studio hiển thị **Xóa**.

| Bước | Thao tác |
| --- | --- |
| 1 | Chọn biểu tượng <img src="https://api.iconify.design/lucide:ellipsis-vertical.svg?color=%23ff3333" width="16" alt="" /> **(Thao tác)** tại dòng cần xóa. |
| 2 | Chọn **Xóa**. |
| 3 | Xác nhận trong hộp thoại của hệ thống. |

> **Cảnh báo:** Kiểm tra Agent và cấu hình đang sử dụng model của kết nối trước khi xóa để tránh làm gián đoạn hoạt động.

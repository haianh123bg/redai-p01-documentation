## Các khu vực chính

| Khu vực | Chức năng |
| --- | --- |
| Danh mục Integration | Khám phá các dịch vụ được RedAI hỗ trợ và bắt đầu kết nối. |
| Tích hợp của tôi | Quản lý các tài khoản, ứng dụng và dịch vụ đã kết nối trong Base hiện tại. |
| AI Studio | Quản lý kết nối với nhà cung cấp LLM, model và dữ liệu cấu hình model. |
| Proxy | Quản lý proxy do người dùng tự mua hoặc tự cung cấp, sau đó gán proxy cho kết nối cần sử dụng. |
| Nhà cung cấp tùy chỉnh | Tạo và quản lý định nghĩa kết nối cho API riêng, LLM tùy chỉnh hoặc Google Cloud Project. |

## Các loại tích hợp

| Loại | Cách nhận biết | Cách cấu hình |
| --- | --- | --- |
| Tích hợp hệ thống | Thẻ tích hợp do hệ thống cung cấp trong danh mục. | Kết nối bằng OAuth, API Key, thông tin tài khoản hoặc biểu mẫu riêng của nhà cung cấp. |
| Tích hợp Community | Thẻ có nhãn **Community**. | Đây là nhà cung cấp tùy chỉnh đã được phát hành cho cộng đồng. Trường cấu hình phụ thuộc vào định nghĩa của từng nhà cung cấp. |
| Nhà cung cấp tùy chỉnh | Được tạo tại tab **Nhà cung cấp tùy chỉnh**. | Người dùng tự khai báo xác thực, biến đầu vào, hướng dẫn sử dụng và ánh xạ HTTP. |

> **Lưu ý:** Không dùng một bộ trường chung cho mọi tích hợp. Phương thức xác thực và thao tác quản lý thay đổi theo từng nhà cung cấp.

## Các phương thức kết nối

| Phương thức | Cách hoạt động |
| --- | --- |
| OAuth | RedAI chuyển người dùng đến màn hình đăng nhập hoặc cấp quyền của nhà cung cấp. Sau khi hoàn tất, kết nối được đưa về Base hiện tại. |
| API Key hoặc credential | Người dùng nhập API Key, Secret, Token, Client ID, Client Secret hoặc thông tin đăng nhập theo biểu mẫu của nhà cung cấp. |
| Biểu mẫu cấu hình riêng | Một số dịch vụ yêu cầu thêm Host, Port, Shop ID, Retailer, Domain, Database, Schema hoặc các trường nghiệp vụ khác. |
| Quy trình có hướng dẫn | Giao diện hiển thị từng bước cần thực hiện, ví dụ cài RedAI CLI hoặc tải tệp OAuth Credentials JSON. |

## Luồng hoạt động

1. Chọn đúng Workspace và Base.
2. Mở module **Integration**.
3. Tìm và chọn thẻ nhà cung cấp cần kết nối.
4. Hoàn thành phương thức xác thực hoặc các trường cấu hình được hiển thị.
5. Mở **Tích hợp của tôi** để quản lý kết nối vừa tạo.
6. Chọn kết nối tại Agent, Workflow hoặc tính năng có hỗ trợ nhà cung cấp đó.

## Lưu ý về dữ liệu và bảo mật

- Chỉ sử dụng credential thuộc quyền quản lý của tổ chức hoặc người dùng.
- Không đưa API Key, Secret, mật khẩu hoặc tệp OAuth Credentials vào nội dung chat, tài liệu công khai hay ảnh chụp chia sẻ bên ngoài.
- Community là nguồn tích hợp do cộng đồng phát hành; cần kiểm tra kỹ nhà phát hành, biến cấu hình và phạm vi API trước khi sử dụng.
- RedAI không bán hoặc cung cấp proxy. Người dùng tự mua hoặc tự chuẩn bị proxy, sau đó thêm vào hệ thống để quản lý và gán sử dụng.
- Khi xóa, RedAI luôn hiển thị bước xác nhận. Chỉ xác nhận sau khi đã kiểm tra đúng Base và đúng bản ghi.

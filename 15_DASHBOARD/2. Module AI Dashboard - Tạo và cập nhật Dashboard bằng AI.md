## Tạo trang Dashboard

| Bước | Thao tác |
| --- | --- |
| 1 | Chọn đúng Base và mở module **AI Dashboard**. |
| 2 | Mở một Dashboard hiện có hoặc chọn biểu tượng <img src="https://api.iconify.design/lucide:plus.svg?color=%23ff3333" width="16" alt="" /> **(Tạo Trang Mới)**. |
| 3 | Mở Chat Panel nếu khu vực này đang thu gọn. |
| 4 | Chọn **Agent Orchestrator (RedAI - Agent Default)** hoặc Agent người dùng đã gắn Skill **RedAI - Module - AI Dashboard**. |

## Chọn nguồn dữ liệu

| Bước | Thao tác |
| --- | --- |
| 1 | Chọn biểu tượng <img src="https://api.iconify.design/lucide:database.svg?color=%23ff3333" width="16" alt="" /> **(Nguồn dữ liệu)** trên thanh công cụ. |
| 2 | Chọn tab **Cá nhân** hoặc **Hệ thống**. |
| 3 | Dùng ô **Tìm kiếm...** hoặc chọn phương thức **GET**, **POST**, **PUT**, **PATCH**, **DELETE** để thu hẹp danh sách. |
| 4 | Mở nhóm Tool cần sử dụng. |
| 5 | Đánh dấu một hoặc nhiều API Tool. |
| 6 | Chọn biểu tượng <img src="https://api.iconify.design/lucide:check.svg?color=%23ff3333" width="16" alt="" /> **(Xác nhận)** ở cuối panel. Các Tool đã chọn được đưa vào Chat Panel làm nguồn cho yêu cầu tiếp theo. |

Trong Chat Panel, người dùng có thể bỏ từng nguồn đã chọn hoặc dùng **Xóa tất cả** để gỡ toàn bộ nguồn khỏi yêu cầu.

> **Lưu ý:** Danh sách nguồn dữ liệu thay đổi theo Base. Chỉ chọn các Tool liên quan trực tiếp đến Dashboard cần tạo.

## Gửi yêu cầu tạo Dashboard

| Bước | Thao tác |
| --- | --- |
| 1 | Nhập yêu cầu vào ô chat, nêu rõ mục tiêu, dữ liệu cần dùng, chỉ số cần hiển thị và cách trình bày mong muốn. |
| 2 | Chọn biểu tượng <img src="https://api.iconify.design/lucide:send.svg?color=%23ff3333" width="16" alt="" /> **(Gửi)**. |
| 3 | Agent sử dụng các nguồn đã chọn để tạo hoặc cập nhật Dashboard đang mở. |

Ví dụ:

```text
Dựa trên các nguồn dữ liệu đã chọn, hãy tạo Dashboard theo dõi hiệu quả quảng cáo.
Hiển thị tổng chi phí, lượt hiển thị, lượt nhấp, CTR, CPC, kết quả theo thời gian
và bảng các chiến dịch có chi phí cao nhưng hiệu quả thấp.
```

## Chỉnh sửa Dashboard bằng hội thoại

Tiếp tục gửi yêu cầu trong cùng cuộc hội thoại để:

- thêm, bỏ hoặc đổi chỉ số;
- thay đổi bố cục, bảng hoặc biểu đồ;
- bổ sung bộ lọc;
- thay đổi cách nhóm hoặc trình bày dữ liệu;
- cập nhật nội dung theo nguồn dữ liệu mới.

Khi cần đọc lại nội dung Dashboard hiện tại, chọn biểu tượng <img src="https://api.iconify.design/lucide:refresh-cw.svg?color=%23ff3333" width="16" alt="" /> **(Tải Lại)**.

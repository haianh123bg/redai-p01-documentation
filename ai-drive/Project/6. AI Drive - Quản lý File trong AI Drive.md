## Mở khu vực quản lý File

| Bước | Cách thực hiện |
| --- | --- |
| 1 | Mở **AI Drive** trên RedAI. |
| 2 | Chọn tab **File** trên thanh điều hướng phía trên. Danh sách File xuất hiện. |
| 3 | Xem các cột **Tên file**, **Định dạng**, **Thẻ**, **Projects**, **Trạng thái RAG** và **Ngày tạo** để xác định File cần quản lý. |

## Các tính năng

### Thao tác với một File

> **Cảnh báo:** Trước khi xóa, kiểm tra cột **Projects**. Project và Agent sẽ không còn sử dụng được nguồn nội dung từ File đã xóa.

| Tính năng | Cách thực hiện |
| --- | --- |
| **Mở menu thao tác** | Tại File cần quản lý, chọn <img src="https://api.iconify.design/lucide:ellipsis-vertical.svg?color=%23ff3333" width="16" alt="" /> **(Thao tác)**. Menu hiển thị các chức năng **Sao chép URL**, **Xem graph**, **RAG lại**, **Chỉnh sửa thông tin**, **Chỉnh sửa file** và **Xóa**. |
| **Sao chép URL của File** | Cách 1: chọn <img src="https://api.iconify.design/lucide:copy.svg?color=%23ff3333" width="16" alt="" /> **(Sao chép)** ngay trên dòng File. Cách 2: trong menu thao tác, chọn **Sao chép URL**. |
| **Xem Graph** | Chọn **Xem graph**. Trong màn hình **Knowledge graph**, kiểm tra số **Nodes**, **Edges**; chọn node để xem nội dung và quan hệ; dùng <img src="https://api.iconify.design/lucide:refresh-cw.svg?color=%23ff3333" width="16" alt="" /> **(Làm mới)** hoặc các nút thu nhỏ, phóng to và toàn màn hình. Chọn <img src="https://api.iconify.design/lucide:x.svg?color=%23ff3333" width="16" alt="" /> **(Đóng)** để quay lại. |
| **RAG lại** | Chọn <img src="https://api.iconify.design/lucide:rotate-ccw.svg?color=%23ff3333" width="16" alt="" /> **(RAG lại)**, sau đó theo dõi cột **Trạng thái RAG** để kiểm tra kết quả xử lý. |
| **Chỉnh sửa nội dung File** | Chọn <img src="https://api.iconify.design/lucide:pencil.svg?color=%23ff3333" width="16" alt="" /> **(Chỉnh sửa file)**, cập nhật nội dung trong trình soạn thảo rồi chọn <img src="https://api.iconify.design/lucide:check.svg?color=%23ff3333" width="16" alt="" /> **(Lưu)**. Theo dõi **Trạng thái RAG** trước khi dùng File làm nguồn cho Agent. Tùy chọn này chỉ xuất hiện với loại File được hỗ trợ. |
| **Chỉnh sửa thông tin File** | Chọn <img src="https://api.iconify.design/lucide:pencil.svg?color=%23ff3333" width="16" alt="" /> **(Chỉnh sửa thông tin)**, cập nhật **Tên tài liệu**, **Mô tả** hoặc **Tags**, sau đó chọn <img src="https://api.iconify.design/lucide:check.svg?color=%23ff3333" width="16" alt="" /> **(Lưu)**. |
| **Xóa File** | Chọn <img src="https://api.iconify.design/lucide:trash-2.svg?color=%23ff3333" width="16" alt="" /> **(Xóa)**. Kiểm tra File trong khung **Xác nhận xóa**, sau đó chọn <img src="https://api.iconify.design/lucide:trash-2.svg?color=%23ff3333" width="16" alt="" /> để xác nhận hoặc <img src="https://api.iconify.design/lucide:x.svg?color=%23ff3333" width="16" alt="" /> **(Hủy)**. |

> **Lưu ý:** **Chỉnh sửa thông tin** chỉ thay đổi tên, mô tả và thẻ; **Chỉnh sửa file** thay đổi nội dung bên trong File. Nếu Graph chưa có dữ liệu, kiểm tra **Trạng thái RAG** và dùng <img src="https://api.iconify.design/lucide:rotate-ccw.svg?color=%23ff3333" width="16" alt="" /> **(RAG lại)** khi cần.

### Thao tác với nhiều File

> **Cảnh báo:** Trước khi xóa nhiều File, kiểm tra số mục đã chọn và cột **Projects**.

| Tính năng | Cách thực hiện |
| --- | --- |
| **Chọn nhiều File** | Đánh dấu ô bên trái từng File cần xử lý. Thanh công cụ hiển thị <img src="https://api.iconify.design/lucide:folder-plus.svg?color=%23ff3333" width="16" alt="" /> **(Thêm vào dự án)** và <img src="https://api.iconify.design/lucide:trash-2.svg?color=%23ff3333" width="16" alt="" /> **(Xóa nhiều)**. |
| **Thêm nhiều File vào Project** | Chọn <img src="https://api.iconify.design/lucide:folder-plus.svg?color=%23ff3333" width="16" alt="" /> **(Thêm vào dự án)**. Tìm và đánh dấu một hoặc nhiều Project trong khung bên phải. Kiểm tra số File và số Project đã chọn, sau đó chọn <img src="https://api.iconify.design/lucide:check.svg?color=%23ff3333" width="16" alt="" /> **(Xác nhận)**. |
| **Xóa nhiều File** | Chọn <img src="https://api.iconify.design/lucide:trash-2.svg?color=%23ff3333" width="16" alt="" /> **(Xóa nhiều)** trên thanh công cụ. Kiểm tra số File trong khung **Xác nhận xóa**, rồi chọn <img src="https://api.iconify.design/lucide:trash-2.svg?color=%23ff3333" width="16" alt="" /> để xác nhận hoặc <img src="https://api.iconify.design/lucide:x.svg?color=%23ff3333" width="16" alt="" /> **(Hủy)**. |
